# 行程段管理功能设计

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。

## 一、功能定位

行程段用于把一个发团按 **日期、目的地** 切分管理。计调通常以「第几天到第几天在某个景点」来规划，例如：

| 行程段 | 日期 | 目的地 |
|---|---|---|
| 喀纳斯段 | 7月1日到7月3日 | 喀纳斯 |
| 阿勒泰段 | 7月4日到7月10日 | 阿勒泰 |

行程段是 **成本侧锚点**。段内通过 **资源安排** 维护具体费用行——用车、酒店、拼出给同行等均为资源，详见《资源安排功能设计》。

第一版重点：

1. 这段行程从哪天到哪天、去哪里。
2. 适用人数（默认取发团总人数）。
3. 段内资源（含拼出）挂在本段下。
4. 应付从资源行 **显式生成**，不在行程段层级单独维护拼出字段。

**不设段级「执行方式」**——同一段内可同时有自营资源（Supplier）和拼出资源（Partner）。

---

## 二、页面结构

嵌在发团详情 **行程段** Tab：

**轻量汇总条 + 行程段列表 + 添加/编辑抽屉**

第一版暂不做：日历视图、拖拽排序、每日详细行程、行程段导出、复杂审批流。

---

## 三、轻量汇总条

展示示例：

**行程2段｜共10天｜资源8项｜应付未生成**

| 指标 | 说明 |
|---|---|
| 行程段数量 | 当前发团拆分几段 |
| 总天数 | 行程段天数合计 |
| 资源项数 | 所有段内资源行合计（含拼出） |
| 应付概况 | 未生成 / 部分 / 已付清（派生） |

右侧主按钮：**添加行程段**。

## 四、行程段列表

### 1. 列表字段

| 字段 | 说明 |
|---|---|
| 行程段名称 | 喀纳斯段、阿勒泰段 |
| 日期范围 | 开始日期到结束日期 |
| 天数 | 系统自动计算 |
| 目的地 | 当前段主要目的地 |
| 适用人数 | 默认取发团总人数，可修改 |
| 资源概况 | 如「资源5项｜拼出2条｜合计 ¥3,600」 |
| 应付状态 | 段内资源应付状态的汇总展示 |
| 备注 | 简短展示 |
| 操作 | 查看、编辑、资源安排、删除 |

### 2. 列表示例

| 行程段 | 日期范围 | 天数 | 目的地 | 资源概况 | 应付状态 | 操作 |
|---|---|---:|---|---|---|---|
| 喀纳斯段 | 7月1日–3日 | 3天 | 喀纳斯 | 资源5项｜¥3,600 | 未生成 | 资源安排 |
| 阿勒泰段 | 7月4日–10日 | 7天 | 阿勒泰 | 资源2项｜拼出1条｜¥8,000 | 部分付款 | 资源安排 |

由常用路线模板带入的段，显示标签 **模板带入**。

## 五、添加 / 编辑行程段抽屉

### 基础信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 行程段名称 | 是 | 如喀纳斯段 |
| 开始日期 | 是 | 必须在发团日期范围内 |
| 结束日期 | 是 | 必须在发团日期范围内 |
| 天数 | 自动 | 系统计算 |
| 目的地 | 是 | 文本输入 |
| 适用人数 | 是 | 默认取发团总人数，可修改 |
| 备注 | 否 | 特殊说明 |

保存后提示：

> 请在「资源安排」中为本段添加用车、酒店、拼出等资源。

**不在行程段表单中录入拼出金额或承接同行**——拼出作为资源种类在资源安排中维护。

---

## 六、编辑行程段规则

| 场景 | 规则 |
|---|---|
| 段内无资源 / 资源均未生成应付 | 全部字段可编辑 |
| 段内存在已生成应付且未付款的资源 | 改日期/人数时提示复核资源；资源金额变更同步应付 |
| 段内存在已付款资源 | 对应资源金额不可改 |
| 发团已结清 | 只读 |
| 发团已关闭 | 只读 |

---

## 七、列表操作

| 操作 | 显示条件 | 说明 |
|---|---|---|
| 添加行程段 | 发团编辑中 | 新增行程段 |
| 查看 | 始终 | 查看详情 |
| 编辑 | 未结清、未关闭 | 修改基础信息 |
| 资源安排 | 始终 | 进入资源安排 Tab 并锁定当前段 |
| 删除 | 段内无资源或未生成应付 | 删除该段 |

**不再有** 行程段级的「生成应付」操作——应付在资源行上显式触发。

---

## 八、校验规则

| 场景 | 提示 |
|---|---|
| 行程段名称为空 | 请填写行程段名称 |
| 日期超出发团范围 | 行程段日期不能超出发团日期 |
| 结束日期早于开始日期 | 结束日期不能早于开始日期 |
| 适用人数 < 1 | 适用人数必须大于0 |
| 删除有资源的行程段 | 当前行程段已有资源，不能删除 |

---

## 九、第一版流程

```text
添加行程段 → 填写日期、目的地、人数 → 进入资源安排 → 添加资源（含拼出）→ 显式生成应付
```

保留能力：行程段列表、添加/编辑行程段、资源安排入口。

暂不做：日历视图、拖拽排序、每日详细行程、段级执行方式、段级拼出金额字段、段级生成应付。
