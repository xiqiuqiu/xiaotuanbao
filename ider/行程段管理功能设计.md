# 行程段管理功能设计

## 一、功能定位

行程段用于把一个团按日期、目的地、执行方式拆分管理。第一版重点解决以下问题：

1. 这段行程从哪天到哪天。
2. 这段行程去哪里。
3. 这段行程由我方自营安排，还是拼出给同行。
4. 后续资源和应付金额应该挂到哪一段上。

示例：

| 行程段 | 日期 | 目的地 | 执行方式 |
|---|---|---|---|
| 喀纳斯段 | 7月1日到7月3日 | 喀纳斯 | 自营安排 |
| 阿勒泰段 | 7月4日到7月10日 | 阿勒泰 | 拼出同行 |

---

## 二、页面结构

行程段放在团单详情 Tab 内，建议结构为：

**轻量汇总条 + 行程段列表 + 添加 / 编辑抽屉**

第一版暂不做以下能力：

| 暂不做功能 | 说明 |
|---|---|
| 日历视图 | 第一版先用列表降低开发复杂度 |
| 拖拽排序 | 通过编辑日期调整即可 |
| 每日详细行程 | 当前重点是行程段和资源成本 |
| 行程段导出 | 第一版暂不需要 |
| 复杂审批流 | 后续版本再扩展 |

---

## 三、轻量汇总条

放在行程段 Tab 顶部，占一行即可。

展示示例：

**行程2段｜共10天｜自营1段｜拼出1段｜资源待确认**

| 指标 | 说明 |
|---|---|
| 行程段数量 | 当前团拆分几段 |
| 总天数 | 行程段天数合计 |
| 自营段数 | 执行方式为自营安排的段数 |
| 拼出段数 | 执行方式为拼出同行的段数 |
| 资源状态 | 未安排、待确认、已确认 |

右侧主按钮：**添加行程段**。

## 四、行程段列表

### 1. 列表字段

| 字段 | 说明 |
|---|---|
| 行程段名称 | 喀纳斯段、阿勒泰段 |
| 日期范围 | 开始日期到结束日期 |
| 天数 | 系统自动计算 |
| 目的地 | 当前段主要目的地 |
| 适用人数 | 默认取团单总人数 |
| 执行方式 | 自营安排、拼出同行 |
| 承接同行 | 仅拼出同行展示 |
| 拼出金额 | 仅拼出同行展示 |
| 资源数量 | 仅自营安排展示 |
| 资源状态 | 未安排、待确认、已确认 |
| 应付状态 | 未生成、已生成、部分付款、已付清 |
| 备注 | 简短展示 |
| 操作 | 查看、编辑、资源安排、生成应付、删除 |

### 2. 列表示例

| 行程段 | 日期范围 | 天数 | 目的地 | 执行方式 | 资源 / 承接同行 | 金额 | 应付状态 | 操作 |
|---|---|---:|---|---|---|---:|---|---|
| 喀纳斯段 | 7月1日到7月3日 | 3天 | 喀纳斯 | 自营安排 | 资源5项 | ¥3,600 | 未生成 | 资源安排 |
| 阿勒泰段 | 7月4日到7月10日 | 7天 | 阿勒泰 | 拼出同行 | 阿勒泰某地接 | ¥8,000 | 未生成 | 生成应付 |

## 五、添加行程段抽屉

### 1. 基础信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 行程段名称 | 是 | 如喀纳斯段 |
| 开始日期 | 是 | 必须在团单日期范围内 |
| 结束日期 | 是 | 必须在团单日期范围内 |
| 天数 | 是 | 系统自动计算 |
| 目的地 | 是 | 文本输入 |
| 适用人数 | 是 | 默认取团单总人数，可修改 |
| 执行方式 | 是 | 自营安排、拼出同行 |
| 备注 | 否 | 特殊说明 |

说明：第一版不建议增加“行程说明”字段，统一用“备注”承接，避免表单过重。

### 2. 执行方式为自营安排

选择 **自营安排** 后，不需要额外金额字段。

页面提示文案：

> 该行程段由我方安排资源，请在资源安排中维护车辆、酒店、导游、餐、门票等资源。

保存后，列表中显示操作：**资源安排**。

### 3. 执行方式为拼出同行

选择 **拼出同行** 后，只展示以下字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 承接同行 | 是 | 选择负责承接该段行程的同行 |
| 结算方式 | 是 | 整段包干、手动金额 |
| 拼出金额 | 是 | 本段需要支付给承接同行的金额 |
| 备注 | 否 | 沟通说明、特殊约定 |

第一版删除以下字段：

| 删除字段 | 原因 |
|---|---|
| 拼出单价 | 拼出场景按整段金额处理即可 |
| 按人结算 | 第一版不做按人结算 |
| 拼出包含内容 | 用备注承接即可 |
| 拼出内容 | 用备注承接即可 |

## 六、编辑行程段规则

| 场景 | 规则 |
|---|---|
| 未生成应付 | 全部字段可编辑 |
| 已生成应付且未付款 | 可编辑，保存后同步应付金额 |
| 已发生付款 | 金额字段禁止修改 |
| 团单已结清 | 只读 |
| 团单已关闭 | 只读 |

金额相关字段包括：

**执行方式、承接同行、结算方式、拼出金额。**

---

## 七、列表操作

| 操作 | 显示条件 | 说明 |
|---|---|---|
| 添加行程段 | 团单编辑中 | 新增行程段 |
| 查看 | 始终显示 | 查看详情 |
| 编辑 | 未结清、未关闭 | 修改行程段 |
| 资源安排 | 自营安排 | 进入资源安排 |
| 生成应付 | 拼出同行且未生成应付 | 生成给承接同行的应付 |
| 删除 | 未生成应付且无资源 | 删除该段 |

如果行程段由路线模板带入，建议在列表中显示标签：**模板带入**。

---

## 八、应付生成规则

拼出同行生成应付时，用户只需要理解：

**承接同行 = 以后要付款的人**  
**拼出金额 = 以后要付款的金额**

点击 **生成应付** 后，系统自动生成应付记录：

| 应付字段 | 来源 |
|---|---|
| 付款对象 | 承接同行 |
| 付款金额 | 拼出金额 |
| 来源行程段 | 当前行程段 |
| 关联团单 | 当前团单 |
| 备注 | 行程段备注 |
| 应付状态 | 待付 |

页面上不建议展示“应付来源”字段，它作为系统内部字段即可。

---

## 九、资源状态

| 状态 | 含义 |
|---|---|
| 未安排 | 没有资源，也没有拼出金额 |
| 待确认 | 模板带入资源或拼出金额还未确认 |
| 已确认 | 自营资源价格已确认，或拼出金额已确认 |

资源状态主要用于列表提醒，不需要用户单独维护。

## 十、校验规则

| 场景 | 提示 |
|---|---|
| 行程段名称为空 | 请填写行程段名称 |
| 日期超出团单范围 | 行程段日期不能超出团单日期 |
| 结束日期早于开始日期 | 结束日期不能早于开始日期 |
| 适用人数小于1 | 适用人数必须大于0 |
| 拼出同行未选承接方 | 请选择承接同行 |
| 拼出金额为空 | 请填写拼出金额 |
| 删除已有资源的行程段 | 当前行程段已有资源，不能删除 |
| 已付款后修改金额 | 当前行程段已发生付款，不允许修改金额 |

---

## 十一、第一版最终流程

第一版行程段管理流程建议为：

**添加行程段 → 填写日期、目的地、人数 → 选择执行方式 → 自营则进入资源安排 → 拼出则填写承接同行和拼出金额 → 生成应付**

最终保留的页面能力为：

| 页面能力 | 说明 |
|---|---|
| 行程段列表 | 查看各行程段的日期、目的地、执行方式和应付情况 |
| 添加行程段 | 新增自营或拼出行程段 |
| 编辑行程段 | 修改基础信息、执行方式和拼出金额 |
| 资源安排入口 | 自营行程段进入资源安排 |
| 拼出同行金额录入 | 拼出行程段填写承接同行和拼出金额 |
| 生成应付 | 拼出同行直接生成给承接同行的应付 |

---

## 十二、第一版范围总结

第一版重点是把行程段做成资源和应付的承载对象，避免功能过重。

保留：

- 行程段列表
- 添加行程段
- 编辑行程段
- 自营安排
- 拼出同行
- 承接同行
- 拼出金额
- 资源安排入口
- 生成应付

暂不做：

- 日历视图
- 拖拽排序
- 每日详细行程
- 拼出按人结算
- 拼出单价
- 拼出包含内容
- 行程段导出
- 独立审批流
