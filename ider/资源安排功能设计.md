# 资源安排功能设计

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。**段内资源**（Segment Resource）统一承载自营与拼出。  
> 工作区总览（布局、段导航、URL、空态）见《[执行安排功能设计](./执行安排功能设计.md)》。本文专写右侧资源区与应付细则。

## 一、功能定位

资源安排是发团详情 **执行安排** Tab 内、当前选中行程段的右侧主表：录入成本费用行，作为后续 **显式生成应付** 和计算发团成本的来源。

计调在段内的操作本质一致：**加车、加酒店、加拼出给同行**——都是添加一条资源，只是种类和对手方不同。

第一版不做复杂计价规则；计调在线下确认明细和总金额后，录入资源种类、对手方、资源金额和备注即可。

核心业务链路：

```text
打开执行安排 → 选中行程段 → 添加资源 → 填写费用项 → 保存 → 显式生成应付
```

说明：保存资源 **不会** 自动生成应付。

---

## 二、适用范围

资源安排适用于 **所有行程段**。每个段内可有多条资源，自营与拼出 **可混合**。

| 资源种类 | 对手方 | 说明 |
|---|---|---|
| 用车、酒店、导游、门票、餐、其他 | **Supplier** | 地接社自行安排 |
| **拼出** | **Partner**（承接方） | 该段部分或全部服务拼给同行 |

---

## 三、入口与上下文

资源区嵌在执行安排右侧，**不是**独立 Tab，也 **不** 从段列表「跳转锁定」进入。

| 项 | 约定 |
|---|---|
| 入口 | 左侧选中行程段后，右侧即展示该段资源主表；标题栏「添加资源」 |
| 当前段 | 由执行安排的选中态与 URL `segmentId` 决定（规则见总览） |
| 副文案 | 示例：`喀纳斯段 · 3 项`（段名、本段资源条数） |
| 换段 | 点击左侧另一段即可；无需返回列表再进入 |

无段 / 本段无资源的空态与添加入口见《执行安排功能设计》第四节。

## 四、页面结构

**当前段副文案 → 资源列表 → 添加 / 编辑资源抽屉**

第一版不做：筛选区、复杂卡片、资源价格确认状态、批量操作。

## 五、资源列表字段

| 字段 | 说明 |
|---|---|
| 资源种类 | 用车、酒店、导游、门票、餐、**拼出**、其他 |
| 对手方 | 自营显示 Supplier；拼出显示 Partner（承接方） |
| 资源项目 | 可选，简单描述 |

| 备注 | 使用日期、数量、明细、特殊约定 |
| 操作 | 编辑、生成应付、删除 |

## 六、添加资源抽屉

### 1. 顶部只读信息

当前行程段名称、日期范围。

### 2. 表单字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 资源种类 | 是 | 用车、酒店、导游、门票、餐、**拼出**、其他 |
| 对手方 | 条件必填 | 种类 = 拼出 → 选择 **Partner**（承接方）；其他 → 选择 **Supplier** |
| 资源项目 | 否 | 如喀纳斯用车、阿勒泰拼出 |
| 资源金额 | 是 | 线下确认后的总金额；允许填 0 |
| 备注 | 否 | 使用日期、数量、明细、特殊约定 |

### 3. 第一版不单独展示的字段

| 字段 | 处理方式 |
|---|---|
| 行程段 | 抽屉顶部只读（由当前选中段决定） |
| 使用日期 / 数量 / 单价 | 写入备注 |
| 计价方式 / 价格状态 | 第一版不做 |

|---|---|---|
| 用车 | Supplier | 包车、接送机 |

## 八、应付状态

| 应付状态 | 含义 |
|---|---|
| 未生成 | 资源已录入，尚未生成应付 |
| 已生成 | 已创建应付收付款节点 |
| 部分付款 | 应付已部分核销 |
| 已付清 | 应付已全部核销 |

已 finance-touched 后，源资源金额变更不静默改应付，显示 **来源差异警示**。

---

## 九、生成应付规则

点击 **生成应付** 后，根据当前资源行创建一条收付款节点（`direction = payable`）：

| 应付字段 | 来源 |
|---|---|
| 付款对象 | 拼出 → Partner；其他 → Supplier |
| 付款金额 | 资源金额 |
| 来源行程段 | 当前行程段 |
| 来源资源 | 当前资源行 |
| 关联发团 | 当前发团 |
| 备注 | 资源备注 |

第一版：**一条资源 → 一条应付**。批量分组生成后续版本再做。

### 金额与留页

| 规则 | 说明 |
|---|---|
| 0 元可存 | 资源金额允许为 0，可保存为未生成应付的费用行（占位 / 待补金额） |
| 0 元不可生成应付 | 金额须 **大于 0** 才能生成应付；否则提示「资源金额须大于 0 才能生成应付」 |
| 生成后留页 | 生成成功后 **不跳转** 离开执行安排；本段资源表刷新，应付状态更新 |
| Toast | 成功提示「应付已生成」；若存在来源金额差异则「应付已生成，存在来源金额差异，请核对」 |

## 十、操作规则

### 1. 添加资源

在当前选中行程段下新增；保存后应付状态默认「未生成」。

### 2. 编辑资源

| 场景 | 规则 |
|---|---|
| 未生成应付 | 全部字段可编辑 |
| 已生成应付且未付款 | 可改资源金额，同步应付 |
| 已发生付款（finance-touched） | 金额不可改，仅可改备注 |
| 已付清 | 只读 |
| 发团已关闭 | 只读 |

### 3. 删除资源

| 场景 | 是否允许 |
|---|---|
| 未生成应付 | 允许 |
| 已生成应付 | 不允许，须先处理应付 |
| 已发生付款 | 不允许 |
| 发团已关闭 | 不允许 |

### 4. 查看

已生成应付或已付款的资源，「编辑」变为「查看」。

## 十一、校验规则

| 场景 | 提示 |
|---|---|
| 未选择资源种类 | 请选择资源种类 |
| 未选择对手方 | 请选择供应商或承接同行 |
| 拼出未选 Partner | 请选择承接同行 |
| 非拼出未选 Supplier | 请选择供应商 |
| 未填写资源金额 | 请填写资源金额 |
| 资源金额 < 0 | 资源金额不能小于0 |
| 金额为 0 时点生成应付 | 资源金额须大于 0 才能生成应付 |
| 已生成应付后删除 | 当前资源已生成应付，不能直接删除 |
| 已付款后改金额 | 当前资源已发生付款，不允许修改金额 |

## 十二、第一版不做

| 功能 | 原因 |
|---|---|
| 资源筛选（种类 / 应付状态 / 关键词） | 第一版右侧仅主表；见总览 Out of scope |
| 使用日期 / 数量 / 单价独立字段 | 放备注 |
| 批量生成应付 | 先做单条 |
| 资源导出 | 后续版本 |
| 按供应商+种类分组应付 | 后续版本 |
| 独立「资源安排」Tab / 锁定段跳转 | 已并入执行安排同屏 |

---

## 十三、第一版流程

```text
执行安排 → 选中行程段 → 添加资源（含拼出）→ 保存 → 生成应付（留页 + Toast）
```

最小能力：当前段资源列表、添加/编辑/删除、生成应付、查看应付状态。
