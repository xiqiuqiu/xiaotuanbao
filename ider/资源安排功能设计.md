# 资源安排功能设计

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。**段内资源**（Segment Resource）统一承载自营与拼出。

## 一、功能定位

资源安排用于在 **行程段** 下录入成本费用行，作为后续 **显式生成应付** 和计算发团成本的来源。

计调在段内的操作本质一致：**加车、加酒店、加拼出给同行**——都是添加一条资源，只是种类和对手方不同。

第一版不做复杂计价规则；计调在线下确认明细和总金额后，录入资源种类、对手方、资源金额和备注即可。

核心业务链路：

```text
添加行程段 → 进入资源安排 → 添加资源 → 填写费用项 → 保存 → 显式生成应付
```

说明：保存资源 **不会** 自动生成应付。

---

## 二、适用范围

资源安排适用于 **所有行程段**。每个段内可有多条资源，自营与拼出 **可混合**。

| 资源种类 | 对手方 | 说明 |
|---|---|---|
| 用车、酒店、导游、门票、餐、其他 | **Supplier** | 地接社自行安排 |
| **拼出** | **Partner**（承接方） | 该段部分或全部服务拼给同行 |

---

## 三、入口设计

### 1. 从行程段进入

在发团详情 **行程段** Tab，每行操作列展示 **资源安排**。

点击后进入 **资源安排** Tab，并 **锁定当前行程段**。

### 2. 上下文展示

顶部只读信息条，示例：

**当前行程段：喀纳斯段｜2026-07-01 至 2026-07-03｜适用人数：18人**

行程段不可在下拉中切换——避免资源误挂到其他段。需换段请返回行程段列表重新进入。

---

## 四、页面结构

**只读行程段信息条 → 筛选区 → 资源列表 → 添加资源抽屉**

第一版不做：复杂卡片、资源价格确认状态、批量操作。

---

## 五、筛选项

| 筛选项 | 类型 | 说明 |
|---|---|---|
| 资源种类 | 下拉 | 用车、酒店、导游、门票、餐、拼出、其他 |
| 应付状态 | 下拉 | 未生成、已生成、部分付款、已付清 |
| 关键词 | 输入框 | 搜索资源名称、对手方、备注 |

按钮：查询、重置、添加资源

已锁定行程段时，不展示行程段筛选。

## 七、添加资源抽屉

### 1. 顶部只读信息

当前行程段名称、日期范围、适用人数。

### 2. 表单字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 资源种类 | 是 | 用车、酒店、导游、门票、餐、**拼出**、其他 |
| 对手方 | 条件必填 | 种类 = 拼出 → 选择 **Partner**（承接方）；其他 → 选择 **Supplier** |
| 资源名称 | 否 | 如喀纳斯用车、阿勒泰拼出 |
| 资源金额 | 是 | 线下确认后的总金额 |
| 备注 | 否 | 使用日期、数量、明细、特殊约定 |

### 3. 第一版不单独展示的字段

| 字段 | 处理方式 |
|---|---|
| 行程段 | 抽屉顶部只读 |
| 使用日期 / 数量 / 单价 | 写入备注 |
| 计价方式 / 价格状态 | 第一版不做 |

## 八、资源种类

| 资源种类 | 对手方 | 示例 |
|---|---|---|
| 用车 | Supplier | 包车、接送机 |
| 酒店 | Supplier | 住宿、房差 |
| 导游 | Supplier | 地陪、全陪 |
| 门票 | Supplier | 景区门票 |
| 餐 | Supplier | 团餐、特色餐 |
| **拼出** | **Partner** | 整段或部分服务拼给同行 |
| 其他 | Supplier | 保险、杂费 |

## 九、应付状态

| 应付状态 | 含义 |
|---|---|
| 未生成 | 资源已录入，尚未生成应付 |
| 已生成 | 已创建应付收付款节点 |
| 部分付款 | 应付已部分核销 |
| 已付清 | 应付已全部核销 |

已 finance-touched 后，源资源金额变更不静默改应付，显示 **来源差异警示**。

---

## 十、生成应付规则

点击 **生成应付** 后，根据当前资源行创建一条收付款节点（`direction = payable`）：

| 应付字段 | 来源 |
|---|---|
| 付款对象 | 拼出 → Partner；其他 → Supplier |
| 付款金额 | 资源金额 |
| 来源行程段 | 当前行程段 |
| 来源资源 | 当前资源行 |
| 关联发团 | 当前发团 |
| 备注 | 资源备注 |

第一版：**一条资源 → 一条应付**。批量分组生成后续版本再做。

---

## 十一、操作规则

### 1. 添加资源

在当前行程段下新增；保存后应付状态默认「未生成」。

### 2. 编辑资源

| 场景 | 规则 |
|---|---|
| 未生成应付 | 全部字段可编辑 |
| 已生成应付且未付款 | 可改资源金额，同步应付 |
| 已发生付款（finance-touched） | 金额不可改，仅可改备注 |
| 已付清 | 只读 |
| 发团已关闭 | 只读 |

### 3. 删除资源

| 场景 | 是否允许 |
|---|---|
| 未生成应付 | 允许 |
| 已生成应付 | 不允许，须先处理应付 |
| 已发生付款 | 不允许 |
| 发团已关闭 | 不允许 |

### 4. 查看

已生成应付或已付款的资源，「编辑」变为「查看」。

---

## 十二、校验规则

| 场景 | 提示 |
|---|---|
| 未选择资源种类 | 请选择资源种类 |
| 未选择对手方 | 请选择供应商或承接同行 |
| 拼出未选 Partner | 请选择承接同行 |
| 非拼出未选 Supplier | 请选择供应商 |
| 未填写资源金额 | 请填写资源金额 |
| 资源金额 < 0 | 资源金额不能小于0 |
| 已生成应付后删除 | 当前资源已生成应付，不能直接删除 |
| 已付款后改金额 | 当前资源已发生付款，不允许修改金额 |

---

## 十三、第一版不做

| 功能 | 原因 |
|---|---|
| 使用日期 / 数量 / 单价独立字段 | 放备注 |
| 批量生成应付 | 先做单条 |
| 资源导出 | 后续版本 |
| 按供应商+种类分组应付 | 后续版本 |

---

## 十四、第一版流程

```text
行程段列表 → 资源安排（锁定段）→ 添加资源（含拼出）→ 保存 → 生成应付
```

最小能力：资源列表、添加/编辑/删除、生成应付、查看应付状态。
