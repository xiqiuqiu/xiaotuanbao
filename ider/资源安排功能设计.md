# 资源安排功能设计

## 一、功能定位

资源安排用于在自营行程段下录入资源费用项，作为后续生成应付和计算团单成本的来源。

第一版资源安排不做复杂计价规则，不做单价、数量、使用日期等细项字段。计调人员在线下确认资源明细和总金额后，在系统中录入资源类型、供应商、资源金额和备注即可。

核心业务链路：

添加自营行程段 → 进入资源安排 → 添加资源 → 填写资源费用项 → 保存 → 生成应付

## 二、适用范围

资源安排只适用于执行方式为“自营安排”的行程段。

| 行程段执行方式 | 是否需要添加资源 | 说明 |
|---|---|---|
| 自营安排 | 需要 | 我方自行安排车、房、导、餐、票等资源 |
| 拼出同行 | 不需要 | 直接在行程段中维护承接同行和拼出金额 |

## 三、入口设计

### 1. 从行程段进入

在团单详情的“行程段”Tab 中，如果某一行程段的执行方式为“自营安排”，操作列展示“资源安排”按钮。

点击“资源安排”后，系统进入团单详情的“资源安排”Tab，并锁定当前行程段。

### 2. 资源安排页上下文展示

进入资源安排页后，顶部展示当前行程段信息，作为只读上下文。

示例：

当前行程段：喀纳斯段｜2026-07-01 至 2026-07-03｜自营安排｜适用人数：18人

说明：

行程段不作为可编辑下拉字段。因为用户是从某个行程段进入资源安排，当前资源应固定归属该行程段，避免误挂到其他行程段。

## 四、页面结构

资源安排页建议采用以下结构：

只读行程段信息条 → 筛选区 → 资源列表 → 添加资源抽屉

第一版不做复杂卡片，不做资源价格确认状态，不做批量操作。

## 五、资源安排页筛选项

| 筛选项 | 类型 | 说明 |
|---|---|---|
| 资源类型 | 下拉 | 用车、酒店、导游、门票、餐、其他 |
| 应付状态 | 下拉 | 未生成、已生成、部分付款、已付清 |
| 关键词 | 输入框 | 搜索资源名称、供应商、备注 |

按钮：查询、重置、添加资源

如果当前页面已经锁定某个行程段，不需要再展示行程段筛选。

## 六、资源列表字段

| 字段 | 说明 |
|---|---|
| 资源类型 | 用车、酒店、导游、门票、餐、其他 |
| 供应商 | 对应资源供应商 |
| 资源名称 | 可选，用于简单描述资源 |
| 资源金额 | 线下确认后的资源总金额 |
| 应付状态 | 未生成、已生成、部分付款、已付清 |
| 备注 | 使用日期、数量、价格明细、包含内容或特殊约定 |
| 操作 | 编辑、生成应付、删除 |

列表展示建议：

| 资源类型 | 供应商 | 资源名称 | 资源金额 | 应付状态 | 备注 | 操作 |
|---|---|---|---:|---|---|---|
| 用车 | 喀纳斯车队 | 喀纳斯段用车 | ¥1,600 | 未生成 | 7月1日至3日，18座中巴 | 编辑 / 生成应付 / 删除 |
| 酒店 | 喀纳斯木山庄 | 禾木景区住宿 | ¥1,200 | 未生成 | 7月1晚，标间6间 | 编辑 / 生成应付 / 删除 |
| 门票 | 喀纳斯景区 | 景区门票 | ¥800 | 已生成 | 成人18人，儿童2人 | 查看 |

## 七、添加资源抽屉

### 1. 顶部只读信息

添加资源抽屉顶部展示当前行程段信息。

| 展示项 | 示例 |
|---|---|
| 当前行程段 | 喀纳斯段 |
| 日期范围 | 2026-07-01 至 2026-07-03 |
| 执行方式 | 自营安排 |
| 适用人数 | 18人 |

该信息仅展示，不允许用户修改。

### 2. 表单字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 资源类型 | 是 | 用车、酒店、导游、门票、餐、其他 |
| 供应商 | 是 | 选择对应供应商 |
| 资源名称 | 否 | 如喀纳斯用车、阿勒泰酒店 |
| 资源金额 | 是 | 线下确认后的资源总金额 |
| 备注 | 否 | 使用日期、数量、价格明细、包含内容或特殊约定 |

备注占位提示建议：

可填写使用日期、数量、价格明细、包含内容或特殊约定

### 3. 不再单独展示的字段

| 字段 | 处理方式 |
|---|---|
| 行程段 | 抽屉顶部只读展示，不允许下拉选择 |
| 使用日期 | 写入备注 |
| 数量 | 写入备注 |
| 单价 | 写入备注 |
| 计价方式 | 第一版不做 |
| 价格状态 | 第一版不做 |

## 八、资源类型

第一版资源类型建议如下：

| 资源类型 | 示例 |
|---|---|
| 用车 | 包车、接送机、区间车 |
| 酒店 | 住宿、房差 |
| 导游 | 地陪、讲解员、全陪 |
| 门票 | 景区门票、区间票 |
| 餐 | 团餐、特色餐 |
| 其他 | 保险、杂费、临时费用 |

## 九、应付状态

资源安排第一版只保留应付状态，不再单独设置资源状态或价格状态。

| 应付状态 | 含义 |
|---|---|
| 未生成 | 资源已录入，还没有生成应付 |
| 已生成 | 已根据资源金额生成应付 |
| 部分付款 | 该应付已部分核销付款 |
| 已付清 | 该应付已全部核销完成 |

## 十、生成应付规则

点击“生成应付”后，系统根据当前资源记录生成一条应付记录。

| 应付字段 | 来源 |
|---|---|
| 付款对象 | 供应商 |
| 付款金额 | 资源金额 |
| 来源行程段 | 当前行程段 |
| 来源资源 | 当前资源记录 |
| 关联团单 | 当前团单 |
| 备注 | 资源备注 |
| 应付状态 | 待付 |

说明：

第一版建议支持单条资源生成应付。这样更容易理解，也方便后续排查某笔应付的来源。

## 十一、操作规则

### 1. 添加资源

可在当前自营行程段下新增资源记录。

保存后资源应付状态默认为“未生成”。

### 2. 编辑资源

| 场景 | 规则 |
|---|---|
| 未生成应付 | 全部字段可编辑 |
| 已生成应付且未付款 | 可编辑资源金额，保存后同步应付金额 |
| 已发生付款 | 金额字段不可修改，只允许修改备注 |
| 已付清 | 只读 |
| 团单已关闭 | 只读 |

金额字段包括：资源金额。

### 3. 删除资源

| 场景 | 是否允许删除 |
|---|---|
| 未生成应付 | 允许删除 |
| 已生成应付 | 不允许直接删除 |
| 已发生付款 | 不允许删除 |
| 团单已关闭 | 不允许删除 |

如果资源已生成应付，需要先处理对应应付记录后再删除。

### 4. 查看资源

已生成应付或已付款的资源，操作建议由“编辑”变为“查看”。

## 十二、校验规则

| 场景 | 提示 |
|---|---|
| 当前行程段不是自营安排 | 该行程段为拼出同行，不需要添加资源 |
| 未选择资源类型 | 请选择资源类型 |
| 未选择供应商 | 请选择供应商 |
| 未填写资源金额 | 请填写资源金额 |
| 资源金额小于0 | 资源金额不能小于0 |
| 已生成应付后删除资源 | 当前资源已生成应付，不能直接删除 |
| 已发生付款后修改金额 | 当前资源已发生付款，不允许修改金额 |

## 十三、第一版不做内容

| 功能 | 原因 |
|---|---|
| 使用日期独立字段 | 第一版放在备注中记录 |
| 数量独立字段 | 第一版放在备注中记录 |
| 单价和计价方式 | 计调线下计算总金额，系统只录入结果 |
| 价格状态 | 录入金额即视为确认金额 |
| 复杂资源明细 | 第一版控制录入成本 |
| 批量生成应付 | 第一版先做单条生成 |
| 资源导出 | 可放到后续版本 |

## 十四、第一版最终流程

行程段列表 → 点击资源安排 → 进入资源安排页并锁定当前行程段 → 添加资源 → 选择资源类型和供应商 → 填写资源金额和备注 → 保存 → 生成应付

第一版最小可用能力：

资源列表、添加资源、编辑资源、删除资源、生成应付、查看应付状态。
