一、客源管理第一版定位

客源管理用于记录当前团单里 每个客户发来的客人、对应团款、优惠、客户已收金额、我方代收金额，并作为后续生成应收的来源。

第一版建议保持轻量，围绕一条主线：

添加客源 → 录入客户和人数 → 录入团款与优惠 → 录入收款拆分 → 生成应收

二、核心命名调整
原概念	第一版建议名称	说明
组团社	客户	对地接社来说，对接方就是客户
客源批次	客源记录	页面可直接叫“客源”
客源名称	系统自动生成	用户不需要手动填写
组团社已收押金	客户已收金额	客户已向客人收取的金额
地接代收金额	我方代收金额	我方需要向客人收取的金额
收款责任	收款方式	表达当前客源的钱款拆分方式
三、页面结构

客源管理嵌在团单详情 Tab 内，建议采用：

轻量汇总条 + 筛选区 + 客源列表 + 添加/编辑抽屉 + 客人名单

不做大汇总卡，不做客源状态，不做批量操作，不做批量导出。

四、轻量汇总条

放在客源管理 Tab 顶部，占一行即可。

展示示例：

客源4条｜总人数18人｜客户3家｜优惠 ¥1,440｜结算金额 ¥18,000｜我方代收 ¥14,400

指标	说明
客源数量	当前客源记录数
总人数	客人人数合计
客户数量	涉及多少个客户
优惠合计	所有客源优惠金额合计
结算金额	优惠后应收金额合计
我方代收	我方需要向客人收取的金额合计

如果空间紧张，可以只展示：

4条客源｜18人｜3家客户｜结算 ¥18,000｜我方代收 ¥14,400

七、客源记录自动生成规则

用户新建时不需要填写客源名称，系统自动生成。

规则建议：

客户名称 + 出团日期 + 发客

例如：

西安某旅行社 7月1日发客

如果同一个客户在同一个团里有多条客源，自动加序号：

第几条	自动名称
第1条	西安某旅行社 7月1日发客
第2条	西安某旅行社 7月1日发客 2
第3条	西安某旅行社 7月1日发客 3

这个字段主要用于列表识别和应收来源追溯，表单里不需要用户录入。

八、添加客源抽屉
1. 基础信息
字段	必填	说明
客户	是	选择同行客户
客人人数	是	只录入总人数
备注	否	可记录儿童、免票、特殊要求等说明

说明：第一版不做成人数、儿童数、免票人数拆分。
如果有儿童、免票或特殊人数，先写在备注里。

2. 团款与优惠
字段	必填	说明
原始团款单价	是	优惠前每人价格
原始应收	自动	原始团款单价 × 客人人数
优惠方式	是	无优惠、整单优惠
优惠金额	条件必填	整单优惠时填写
优惠备注	否	记录优惠说明
结算金额	自动	原始应收减优惠金额

第一版不做：

功能	处理方式
按人优惠	用户直接填写整单优惠
抹零类型	通过整单优惠体现
优惠原因	用优惠备注承接
人均结算价	不展示
3. 收款信息
字段	必填	说明
收款方式	是	全部我方代收、客户已收 + 我方代收、客户结算
客户已收金额	条件必填	客户已经向客人收取的金额
我方代收金额	条件必填	我方需要向客人继续收取的金额
结算说明	否	如客户已收部分年底统一结算
九、收款方式规则
收款方式	客户已收金额	我方代收金额	说明
全部我方代收	0	等于结算金额	客户未收款，我方向客人收全款
客户已收 + 我方代收	用户填写	结算金额减客户已收金额	客户先收部分，我方收剩余部分
客户结算	等于结算金额	0	客户收完全款，后续客户与我方结算

这里需要注意：客户已收金额也要进入应收跟踪，因为这部分最终仍然需要客户与我方结算。

十、编辑客源规则
情况	编辑规则
未生成应收	全部字段可编辑
已生成应收且未收款	可编辑金额，保存后同步更新应收
已发生收款	金额字段禁止修改，只允许修改备注
已收齐	只读
团单已关闭	只读

金额字段包括：

客人人数、原始团款单价、优惠金额、客户已收金额、我方代收金额。

十一、列表操作
操作	说明
添加客源	新增一条客源记录
查看	查看客源详情
编辑	修改客源信息
客人名单	维护游客明细
生成应收	根据该客源生成应收
删除	未生成应收时允许删除

删除规则：

情况	是否允许删除
未生成应收	允许删除
已生成应收	不允许直接删除，需要先处理应收
已发生收款	不允许删除

第一版不做：

客源状态、确认客源、批量生成应收、批量确认、批量导出。

十二、客人名单功能

客人名单作为辅助信息，不作为第一版主流程。

字段	说明
姓名	游客姓名
手机号	可选
性别	男、女、未知
备注	儿童、免票、特殊饮食、住宿要求等

操作：

添加客人、编辑客人、删除客人、同步人数

点击 同步人数 后，用客人名单数量回填客人人数。

十三、金额计算规则
项目	规则
原始应收	原始团款单价 × 客人人数
优惠金额	整单优惠金额
结算金额	原始应收减优惠金额
我方代收金额	结算金额减客户已收金额
客源结算金额合计	所有客源结算金额汇总
客户已收金额合计	所有客源客户已收金额汇总
我方代收金额合计	所有客源我方代收金额汇总
十四、校验规则
场景	提示
客户为空	请选择客户
客人人数小于1	客人人数必须大于0
原始团款单价为空	请填写原始团款单价
优惠金额大于原始应收	优惠金额不能大于原始应收
客户已收金额大于结算金额	客户已收金额不能大于结算金额
我方代收金额不匹配	我方代收金额需等于结算金额减客户已收金额
已发生收款后修改金额	当前客源已发生收款，暂不允许修改金额
已生成应收后删除	当前客源已生成应收，不能直接删除
