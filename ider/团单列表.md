# 发团列表

> 领域术语：**发团**（Departure），见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。下文「发团」= 原稿「团单」。

## 一、发团管理第一期业务定位

发团管理用于地接社围绕一个出团批次，完成 **建团、复用常用路线、录入客源单、拆分行程段、安排资源（含拼出）、显式生成收付款节点、核销结算** 的完整业务闭环。

第一期核心目标是：减少重复录入，提高建团效率，同时避免财务金额因复制历史数据产生错误。

核心链路：

```text
选择常用路线建团 → 带出执行安排结构（资源金额为 0）→ 添加客源单 → 段内添加资源 → 显式生成应收/应付 → 核销收付款 → 结清 → 关闭发团
```

说明：保存客源单或资源 **不会** 自动生成收付款节点；计调在事实确认后手动触发。

## 二、核心概念定义

### 1. 常用路线（Route Template）

Organization 内常发线路的配置快照，例如：喀纳斯阿勒泰10日线、北疆环线8日线。定案见 `docs/adr/0008-route-template-structure-only.md`。

| 内容 | 是否保存 | 说明 |
|---|---|---|
| 路线名称 | 保存 | 如喀纳斯阿勒泰10日线；组织内同名禁止 |
| 默认天数 | 保存 | 如10天 |
| 行程段结构 | 保存 | 喀纳斯段3天、阿勒泰段7天；无段不可存 |
| 段内资源草稿 | 保存 | 资源类型、供应商/承接方、资源项目（含拼出种类）；有段无资源可存 |
| 资源金额 | 恒为 0 | 不作参考价模板能力（金额为本团总价） |
| 客源信息 | 不保存 | 每次团的客户和人数不同 |
| 收付款节点 | 不保存 | 财务单据不能复制 |
| 流水核销 | 不保存 | 历史收付款不能复制 |

核心原则：常用路线只固化执行安排结构，不保存交易结果与有业务意义的资源金额。选路线建团为 **一次性复制结构（金额 0）、之后脱钩**。

### 2. 发团类型（Departure Type）

发团层级的 **展示标签**，表达成团方式，不改变业务规则。

| 发团类型 | 含义 |
|---|---|
| 独立团 / 单团 | 通常只有一条客源单 |
| 拼团 | 通常有多条客源单 |

默认建议：拼团。系统 **不** 限制客源单数量——独立团即恰好只有一条客源单的发团。

### 3. 出团进度（Departure Progress）

由出团日期与结束日期 **自动派生**，与发团业务状态独立。

| 出团进度 | 判断规则 |
|---|---|
| 未开始 | 当前日期早于出团日期 |
| 进行中 | 当前日期在出团日期和结束日期之间 |
| 已结束 | 当前日期晚于结束日期 |

### 4. 发团状态（Departure Status）

表达业务处理阶段。

| 发团状态 | 含义 | 流转 |
|---|---|---|
| 编辑中 | 发团资料还在维护 | 初始状态 |
| 待结算 | 进入收付款跟进阶段 | OP 手动切换；**不等于** 已生成全部收付款节点 |
| 已结清 | 应收已收齐、应付已付清 | 收付款节点全部结清或关闭后 **系统判定**（可提示 OP 确认） |
| 已关闭 | 发团归档，只读 | OP 手动触发 |

## 三、发团列表页

### 1. 页面目标

查看所有发团的出团进度、资料完成情况、财务结果和后续待办。

### 2. 筛选条件

| 筛选项 | 说明 |
|---|---|
| 团号 / 团名 | 模糊搜索 |
| 路线名称 | 选择或输入 |
| 发团类型 | 独立团、拼团 |
| 出团日期 | 日期范围 |
| 出团进度 | 未开始、进行中、已结束 |
| 发团状态 | 编辑中、待结算、已结清、已关闭 |
| 负责人 | 计调负责人 |
| 发客客户 | 客源单上的 Partner |

### 3. 列表字段

| 字段 | 说明 |
|---|---|
| 团号 | 系统自动生成，可手动修改 |
| 团名 | 如喀纳斯阿勒泰10日线 7月1日团 |
| 路线名称 | 当前发团使用的路线（实例快照） |
| 发团类型 | 独立团、拼团（标签） |
| 出团日期 | 开始日期 |
| 结束日期 | 结束日期 |
| 出团进度 | 未开始、进行中、已结束 |
| 发团状态 | 编辑中、待结算、已结清、已关闭 |
| 总人数 | 客源单人数合计 |
| 完成情况 | 小标签展示 |
| 实际应收 | 客源单结算金额合计 |
| 应付合计 | 段内资源金额合计 |
| 预估毛利 | 实际应收减应付合计 |
| 负责人 | 计调负责人 |
| 操作 | 查看、编辑、复制、关闭 |

### 4. 完成情况小标签

展示示例：`客源3单｜行程2段｜资源5项｜应收未生成｜应付未生成`

| 类型 | 标签示例 |
|---|---|
| 客源 | 客源未录入、客源3单 |
| 行程 | 行程未录入、行程2段 |
| 资源 | 资源未安排、资源5项 |
| 应收 | 应收未生成、应收已生成、已收齐 |
| 应付 | 应付未生成、应付已生成、已付清 |
