## 建议的权限原则

角色权限建议分成三层：

**菜单是否显示、页面是否可进入、进入后可操作到什么程度。**

同一个功能可以让两个角色都看到，但操作权限不同，避免计调无法了解团单经营情况，也避免财务数据被随意修改。

## 计调角色

### 左侧菜单

建议显示：

* 工作台
* 发团管理
* 合作伙伴
* 供应商管理

建议隐藏：

* 财务管理全部菜单
* 组织管理
* 员工管理

系统管理仅对管理员显示，计调默认不展示。

### 团单详情

建议显示：

* 概览
* 客源管理
* 执行安排
* 应收管理
* 应付管理

建议隐藏：

* 收支流水
* 核销记录

计调在应收、应付中的权限建议控制为：

* 查看账款状态和金额
* 从客源或资源生成应收、应付
* 查看已收、未收、已付、未付
* 不允许登记流水
* 不允许核销、撤销核销
* 不允许修改已收、已付金额
* 不允许关闭账款

概览中的结算应收、成本、毛利、收付款进度可以展示，便于计调控制团单利润和执行情况。

## 财务角色

### 左侧菜单

建议显示：

* 工作台
* 发团管理
* 合作伙伴
* 供应商管理
* 财务管理

  * 应收管理
  * 应付管理
  * 收支流水
  * 核销管理

建议隐藏：

* 组织管理
* 员工管理

财务需要查看合作伙伴和供应商的结算信息、历史往来与账期，因此这两个菜单应保留，但默认只读。

### 团单详情

建议全部显示：

* 概览
* 客源管理
* 执行安排
* 应收管理
* 应付管理
* 收支流水
* 核销记录

其中：

* 客源管理只读
* 执行安排只读
* 应收、应付可维护账期、备注和账款状态
* 收支流水可新增、作废、关联团单
* 核销记录可核销和撤销
* 不允许修改团单路线、人数、行程和资源内容

## 推荐权限矩阵

| 功能       | 计调       | 财务     |
| -------- | -------- | ------ |
| 发团管理     | 新建、编辑、执行 | 查看     |
| 客源管理     | 新建、编辑    | 查看     |
| 执行安排     | 新建、编辑    | 查看     |
| 生成应收     | 可以       | 可以     |
| 生成应付     | 可以       | 可以     |
| 修改应收应付金额 | 受限       | 可以     |
| 收支流水     | 隐藏       | 完整权限   |
| 核销管理     | 隐藏       | 完整权限   |
| 合作伙伴     | 编辑业务信息   | 查看结算信息 |
| 供应商管理    | 编辑业务信息   | 查看结算信息 |
| 组织与员工    | 隐藏       | 隐藏     |

## 页面展示建议

团单顶部 Tab 不建议直接按角色删除过多内容。计调隐藏“收支流水、核销记录”即可，财务保留全部 Tab，但将客源和执行页设置为只读。

后续可以增加“管理员”角色，拥有组织管理、员工管理及全部业务权限。这样权限边界最清晰，也方便小型旅行社老板使用管理员账号查看全局。
