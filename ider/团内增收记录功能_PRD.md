# 团内增收记录功能 PRD

## 1. 文档信息

- **产品名称**：小团宝
- **功能名称**：团内增收记录
- **版本范围**：第一期
- **适用端**：旅行社后台管理端
- **主要角色**：计调、财务、管理员

## 2. 背景与目标

地接社在团单执行过程中，除团款收入外，还会产生购物店返利、车销收入、自费项目返利等额外收入。部分收入还需要向导游支付提成。

当前系统仅管理客源收入、资源成本、应收、应付和流水，缺少团款之外的增收登记与统计能力，导致相关金额只能在线下表格或聊天记录中维护。

第一期目标：

1. 支持按团登记购物店返利、车销收入、自费项目返利和其他增收。
2. 支持记录导游提成。
3. 自动计算公司实际增收。
4. 支持查看结算状态和单团增收汇总。
5. 保持功能轻量，暂不接入应收、应付和核销流程。

## 3. 产品定位

“团内增收”用于管理团款之外产生的附加收入。

该功能与资源成本分开管理：

- 资源成本：酒店、用车、导游、保险、大门票等需要地接社支付的费用。
- 团内增收：购物店返利、车销收入、自费项目返利等由合作方或游客消费带来的额外收益。

购物店、景区、自费项目经营方仍统一维护在“供应商管理”中。在增收记录中统一称为“合作方”。

## 4. 功能入口

在团单详情中新增页签：

**概览｜客源管理｜行程段｜资源安排｜增收记录｜应收管理｜应付管理｜核销记录**

“增收记录”放在“资源安排”之后，便于计调在团执行过程中登记，财务后续查看结算情况。

## 5. 增收类型

| 类型 | 适用场景 | 增收金额含义 |
|---|---|---|
| 购物店返利 | 游客进入特产店、玉石店等消费后，门店向旅行社返款 | 合作方应返金额 |
| 车销收入 | 导游或工作人员在车上销售干果、纪念品等商品 | 商品销售收入 |
| 自费项目返利 | 游船、演出、小景点或娱乐项目等游客自费项目 | 项目返利金额 |
| 其他增收 | 无法归入以上类型的临时收益 | 实际增收金额 |

统一字段名称使用 **增收金额**，根据增收类型显示对应的字段提示。

## 6. 页面结构

### 6.1 顶部统计

| 统计项 | 计算规则 |
|---|---|
| 增收金额合计 | 当前团单全部有效记录的增收金额之和 |
| 导游提成合计 | 当前团单全部有效记录的导游提成之和 |
| 公司增收合计 | 增收金额合计－导游提成合计 |

### 6.2 筛选条件

- 增收类型
- 收入状态
- 提成状态
- 合作方
- 关键词搜索：项目名称、备注

第一期可优先实现增收类型和结算状态筛选，其他条件按实际开发成本决定。

### 6.3 列表字段

| 字段 | 说明 |
|---|---|
| 增收类型 | 购物店返利、车销收入、自费项目返利、其他增收 |
| 项目名称 | 干果销售、游船票、民俗演出等 |
| 合作方 | 购物店、景区或项目经营方，车销时可为空 |
| 增收金额 | 本次确认的收入金额 |
| 导游 | 关联本团导游，可为空 |
| 导游提成 | 本次应支付给导游的金额 |
| 公司增收 | 增收金额－导游提成 |
| 收入状态 | 未收、已收 |
| 提成状态 | 未付、已付 |
| 备注 | 人数、商品、结算约定等补充信息 |
| 操作 | 编辑、删除、标记已收、标记已付 |

## 7. 新增与编辑字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 增收类型 | 是 | 单选：购物店返利、车销收入、自费项目返利、其他增收 |
| 项目名称 | 是 | 最多50字 |
| 合作方 | 否 | 从供应商中选择；购物店返利、自费项目返利时建议填写 |
| 发生日期 | 否 | 默认当前日期，可修改 |
| 增收金额 | 是 | 大于等于0，最多保留两位小数 |
| 导游 | 否 | 从当前团单已安排导游中选择 |
| 导游提成 | 是 | 默认0，不得大于增收金额 |
| 公司增收 | 自动 | 增收金额－导游提成，只读 |
| 收入状态 | 是 | 未收、已收，默认未收 |
| 提成状态 | 是 | 未付、已付，默认未付 |
| 备注 | 否 | 最多200字 |

### 7.1 动态字段提示

- 购物店返利：增收金额提示“请输入合作方应返金额”。
- 车销收入：增收金额提示“请输入商品销售收入”。
- 自费项目返利：增收金额提示“请输入项目返利金额”。
- 其他增收：增收金额提示“请输入实际增收金额”。

## 8. 业务规则

### 8.1 公司增收计算

**公司增收 = 增收金额－导游提成**

示例：

- 增收金额：¥3,000
- 导游提成：¥600
- 公司增收：¥2,400

### 8.2 状态规则

收入与提成分别维护状态，避免出现返利已收到、导游提成尚未支付时无法准确表达的问题。

- 收入状态：未收、已收
- 提成状态：未付、已付

页面可根据两个状态派生一个综合状态：

| 收入状态 | 提成状态 | 综合状态 |
|---|---|---|
| 未收 | 未付 | 待结算 |
| 已收 | 未付 | 待付提成 |
| 未收 | 已付 | 待收增收 |
| 已收 | 已付 | 已结算 |

综合状态仅用于展示，无需单独存储。

### 8.3 删除规则

- 未结算记录允许删除。
- 已收或已付记录删除时弹出二次确认。
- 第一期间不做财务凭证关联，删除后仅影响当前团单的增收统计。

## 9. 权限建议

| 角色 | 权限 |
|---|---|
| 计调 | 新增、编辑、查看、删除未结算记录 |
| 财务 | 查看、编辑金额、标记已收、标记已付 |
| 管理员 | 全部权限 |

第一期若权限系统暂未细分，可沿用团单编辑权限。

## 10. 与现有模块的关系

### 10.1 与供应商管理

购物店、景区、自费项目经营方继续存放在供应商管理中，无需新增购物店管理或景区管理。

供应商类型建议包含：

- 酒店
- 用车
- 导游
- 保险
- 景区
- 购物店
- 餐饮
- 其他

同一供应商可以在资源安排中作为成本提供方，也可以在增收记录中作为返利合作方。

### 10.2 与资源成本

增收记录不计入资源成本，不参与应付合计。

### 10.3 与团单概览

团单概览可增加以下指标：

- 团内增收
- 导游提成
- 增收净收益

建议将“增收净收益”纳入团单利润计算时单独展示，第一期暂不直接改动现有毛利公式，避免影响已有统计口径。

## 11. 第一版本期范围

第一期实现：

1. 团单内新增“增收记录”页签。
2. 支持四种增收类型。
3. 支持增收金额、导游提成和公司增收计算。
4. 支持收入状态与提成状态。
5. 支持新增、编辑、删除和筛选。
6. 支持单团统计汇总。
7. 合作方复用供应商数据。

## 12. 第一版暂不实现

- 不记录游客实际消费总额。
- 不配置返利比例、按人数或按销售额计算规则。
- 不记录商品数量、单价和库存。
- 不拆分多个导游的提成。
- 不支持部分收款和部分付款。
- 不自动生成应收单或应付单。
- 不接入收支流水和核销。
- 不做审批流程。
- 不做跨团对账单。
- 不做供应商返利协议管理。

## 13. 后续扩展方向

后续根据客户使用情况，可逐步增加：

1. 增收记录生成应收单。
2. 导游提成生成应付单。
3. 收支流水与核销。
4. 按合作方生成返利对账单。
5. 支持游客消费金额和返利比例。
6. 支持车销商品明细和库存。
7. 支持多导游提成分配。
8. 将增收净收益纳入团单最终利润。

## 14. 验收标准

1. 用户可在指定团单内新增四种类型的增收记录。
2. 增收金额与导游提成录入后，公司增收实时计算正确。
3. 合作方可从现有供应商中选择。
4. 车销收入允许不选择合作方。
5. 收入状态与提成状态可独立维护。
6. 顶部统计与列表有效记录金额保持一致。
7. 删除或编辑记录后，统计数据实时更新。
8. 不影响现有资源成本、应收、应付和核销数据。
