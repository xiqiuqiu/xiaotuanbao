# 发团详情页 · 头部与 Tab

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。

## 一、页面结构

发团详情页：**顶部经营概览 + Tab 页**。

顶部概览为 **跨子单元的只读汇总**（Read Model），不是写入入口。应收来自客源单，应付来自段内资源，财务结清状态来自 Finance 上下文。

## 二、顶部概览字段

| 字段 | 说明 |
|---|---|
| 团号 / 团名 | 当前发团识别信息 |
| 路线名称 | 建团时的路线实例快照 |
| 发团类型 | 独立团、拼团（标签） |
| 出团日期 / 结束日期 | 团期范围 |
| 出团进度 | 未开始、进行中、已结束（日期派生） |
| 发团状态 | 编辑中、待结算、已结清、已关闭 |
| 总人数 | 客源单人数合计 |
| 原始应收 | 客源单优惠前收入合计 |
| 优惠合计 | 客源单优惠汇总 |
| 实际应收 | 原始应收减优惠 |
| 应付合计 | 段内资源金额合计（含拼出） |
| 预估毛利 | 实际应收减应付合计 |
| 已收 / 未收 | 收付款节点核销结果 |
| 已付 / 未付 | 收付款节点核销结果 |

## 三、Tab 结构

```text
概览｜客源管理｜行程段｜资源安排｜应收管理｜应付管理｜核销记录｜变更记录
```

| Tab | 所属上下文 | 说明 |
|---|---|---|
| 概览 | Departure | 发团基本信息、状态切换 |
| 客源管理 | Departure | 客源单 CRUD，收入侧源事实 |
| 行程段 | Departure | 行程段 CRUD，成本侧锚点 |
| 资源安排 | Departure | 段内资源列表（含拼出），可锁定某行程段 |
| 应收管理 | Finance | 复用财务 Workspace，按发团 scope 过滤 |
| 应付管理 | Finance | 同上 |
| 核销记录 | Finance | 同上 |

应收/应付/核销 Tab 展示的是 **收付款节点**（payment schedule），不是发团子实体。
