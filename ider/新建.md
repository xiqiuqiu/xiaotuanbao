# 新建发团

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。  
> 常用路线定案见 `docs/adr/0008-route-template-structure-only.md`。  
> 交互参考：旅业通「新建团单」概念图（2026-07）；领域模型与 Tab 结构以小团宝 PRD 为准，**不**照搬 Day 级行程、独立游客名单 Tab、费用汇总 Tab。

## 一、入口与整体形态

**入口**：发团列表页主按钮 **新建发团**。

**形态**：宽 Drawer 或 Modal 内的 **两步向导**（非单页堆叠所有字段）。

| 步骤 | 标题 | 内容 |
|---|---|---|
| Step 1 | 选择路线 | 常用路线卡片 / 手动输入 |
| Step 2 | 填写发团信息 | 基础信息表单 + 已选路线摘要 |

顶部展示 **Steps 步骤条**（1 选择路线 → 2 填写信息）。底部：**上一步** / **下一步** 或 **创建发团**。

地接社建团心智为「先定线路、再定团期」；两步向导比单页 Drawer 更清晰，也避免未选路线就误保存。

---

## 二、Step 1：选择路线

### 1. Tab 切换

| Tab | 说明 |
|---|---|
| **常用路线** | 卡片网格 + 搜索（默认 Tab） |
| **手动输入** | 填路线名称与默认天数，不选常用路线；路线来源记 `manual`，**不** 带出执行安排 |

### 2. 常用路线卡片（网格）

搜索框置于 Tab 内容区顶部，支持按路线名称模糊搜索。

每张卡片展示：

| 字段 | 说明 |
|---|---|
| 路线名称 | 如「西安-青海湖-茶卡6日游」 |
| 默认天数 | 如「6 天」 |
| 使用次数 | 该常用路线被用于建团的累计次数（`usageCount`） |
| 最近使用 | 可选，第二版；第一版可仅展示使用次数 |
| 删除 | 卡片右上角删除按钮；确认后删除该常用路线（不影响已建发团） |

第一版 **不做** 路线类型标签（如「国内游」）；若需识别，用路线名称或备注区分。

卡片点击即选中；选中态高亮边框。支持 **单选**。

**删除常用路线**（第一版唯一维护手段；更新靠另存新名）：

1. 点击卡片删除按钮（`stopPropagation`，不触发选中）
2. 弹出确认：「确定删除常用路线「xxx」？删除后不可恢复，不影响已用该路线创建的发团。」
3. 确认后调用删除 API；若当前已选中该路线则清除选中

### 3. 底部固定条（Step 1）

选中常用路线后，Drawer 底部展示：

```text
已选：西安-青海湖-茶卡6日游（6 天）  [清除]     [下一步]
```

- **清除**：取消选中，禁用「下一步」
- **下一步**：直接进入 Step 2（**无** copy 确认窗）

**手动输入 Tab**：填完路线名称（必填）与默认天数（可选）后，底部 **[下一步]** 直接进入 Step 2。

## 三、选常用路线建团的复制规则

选中常用路线并创建发团时，服务端 **固定** 复制执行安排结构：

| 内容 | 行为 |
|---|---|
| 行程段结构 | 恒复制（名称、目的地、天数等；按新出团日与段 `dayCount` 分配日期） |
| 段内资源草稿 | 恒复制（种类、对手方、资源名称等） |
| 资源金额 | 恒为 0（不作参考价模板能力） |
| 客源 | 不复制 |
| 收付款节点 / 流水 | 不复制 |

**不** 弹出分层 copy 确认窗，**不** 提供「复制行程段 / 资源配置 / 参考价格」勾选。若只需空手建团，走 **手动输入** Tab。

复制完成后，常用路线与发团实例 **脱钩**——后续改/删常用路线不影响已建发团；`sourceTemplateId` 仅作追溯。建团成功时该常用路线 `usageCount + 1`。

## 四、Step 2：填写发团信息

### 1. 布局

- **左侧（主区）**：基础信息表单
- **右侧（摘要卡，只读）**：已选路线信息

摘要卡示例（选常用路线建团）：

```text
已选路线
西安-青海湖-茶卡6日游
默认 6 天｜将带出执行安排结构（资源金额为 0）
```

手动输入时摘要卡展示用户填写的路线名称与天数，文案为「手动输入，不带出执行安排」。

### 2. 字段设计

| 模块 | 字段 | 必填 | 说明 |
|---|---|---|---|
| 建团方式 | 选择路线 | 是 | Step 1 已完成；此处只读展示或摘要卡呈现 |
| 建团方式 | 路线来源 | 系统记录 | 常用路线、手动输入、复制发团 |
| 基础信息 | 团名 | 是 | 默认按路线名称 + 出团日期生成，可修改 |
| 基础信息 | 团号 | 是 | 默认自动生成，可手动修改；旁侧 **重新生成** 按钮 |
| 基础信息 | 发团类型 | 是 | 独立团、拼团（展示标签，默认拼团） |
| 基础信息 | 出团日期 | 是 | 团开始日期 |
| 基础信息 | 结束日期 | 是 | 选择路线后可按默认天数自动计算 |
| 基础信息 | 团期天数 | 是 | 系统自动计算（结束 − 开始 + 1） |
| 基础信息 | 发团负责人 | 是 | 计调负责人，默认当前 User |
| 基础信息 | 备注 | 否 | 特殊说明 |

**团号重新生成**：点击刷新图标调用 API 生成新团号（org 内唯一），替换输入框内容。

**日期联动**：修改出团日期 → 若已从常用路线带出默认天数，自动重算结束日期与团名中的日期部分。

### 3. 底部操作

```text
[上一步]                              [创建发团]
```

创建成功：关闭向导 → 跳转发团详情页 `?tab=overview`（或客源 Tab，产品可再定）。

## 五、与概念图的刻意差异

| 概念图（旅业通） | 小团宝 | 原因 |
|---|---|---|
| 用语「团单」 | **发团** | 产品用语 |
| 详情 Tab「行程安排」D1–D6 | **执行安排** Tab（区内行程段导航 + 资源主表） | 规划单元为 Segment；段与资源同屏，非独立 Tab |
| 独立 Tab「游客名单」 | 名单在 **客源单抽屉** | 客人归属客源单 |
| Tab「费用汇总 / 账单明细」 | 头部 Read Model + 应收/应付/核销 | PRD Out of Scope |
| 建团时勾选「生成应收应付」 | 不做；建团后 **显式触发** | ADR：保存源事实不生成节点 |
| 建团分层 copy / 参考价格勾选 | **不做**；结构恒带、金额恒 0 | ADR-0008 |

## 六、保存为常用路线

### 1. 入口

发团详情页右上角：**保存为常用路线**。

| 场景 | 说明 |
|---|---|
| 手动输入路线后 | 想沉淀为常用路线 |
| 调整完行程段后 | 想保存为下次可复用结构 |
| 配好常用资源后 | 想下次直接带出资源草稿（金额为 0） |

### 2. 保存弹窗字段

| 字段 | 默认 | 说明 |
|---|---|---|
| 路线名称 | 当前路线名称 | 可修改；组织内同名禁止（冲突时提示改名） |
| 默认天数 | 当前团期天数 | 自动带出，可改 |

**不** 提供「保存行程段 / 资源配置 / 参考价格」等分层勾选：有行程段时固定快照段结构与段内资源草稿，资源金额写入为 0；无行程段不可保存；有段无资源可保存。不保存客源、收付款节点与流水。

提示文案：

> 常用路线仅保存行程段结构与段内资源草稿，资源金额为 0；不保存客源单、收付款节点和流水信息。

### 3. 保存成功反馈

保存成功后：

1. **Toast**：「常用路线已保存，可在新建发团时选用」
2. Modal 关闭，留在当前详情页
3. 可选第二版：**「去新建发团试用」** 链至列表页并打开新建向导

## 七、复制已有发团（列表操作）

列表操作列 **复制** 与新建向导 **共用 Step 2 表单**，但 Step 1 跳过：

- 路线来源记 `copy`
- **固定** 复制执行安排结构，资源金额恒为 0（与选常用路线规则相同）
- **无** copy 确认窗 / 分层勾选
- **不** 复制客源、收付款节点、流水
- 团名、团号、日期、负责人需重新填写或重新生成

可在 Step 2 摘要卡注明：「复制自发团 TDxxxx，不含客源与财务」。
