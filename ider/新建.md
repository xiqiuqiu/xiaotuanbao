# 新建发团

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。

## 一、页面结构

新建发团第一块放 **选择常用路线**——地接社建团通常从惯发路线开始。

## 二、字段设计

| 模块 | 字段 | 必填 | 说明 |
|---|---|---|---|
| 建团方式 | 选择路线 | 是 | 可搜索常用路线，也可手动输入新路线 |
| 建团方式 | 路线来源 | 系统记录 | 常用路线、手动输入、复制发团 |
| 基础信息 | 团名 | 是 | 默认按路线名称 + 出团日期生成，可修改 |
| 基础信息 | 团号 | 是 | 默认自动生成，可手动修改 |
| 基础信息 | 发团类型 | 是 | 独立团、拼团（展示标签，默认拼团） |
| 基础信息 | 出团日期 | 是 | 团开始日期 |
| 基础信息 | 结束日期 | 是 | 选择路线后可按默认天数自动计算 |
| 基础信息 | 团期天数 | 是 | 系统自动计算 |
| 基础信息 | 发团负责人 | 是 | 计调负责人 |
| 基础信息 | 备注 | 否 | 特殊说明 |

## 三、选择常用路线后的确认项

选择路线后，弹出轻量确认：

| 复制内容 | 默认值 | 说明 |
|---|---|---|
| 复制行程段 | 勾选 | 自动生成当前发团行程段 |
| 复制资源配置 | 勾选 | 自动生成资源草稿（含拼出种类草稿） |
| 带出参考价格 | 勾选 | 金额作为参考价格 |
| 复制客源 | 禁用 | 客源单不能复制 |
| 生成应收应付 | 禁用 | 收付款节点不能复制 |

按钮：**使用该路线建团**。

复制完成后，常用路线与发团实例 **脱钩**——后续改模板不影响已建发团。

## 四、保存为常用路线

### 1. 入口

发团详情页右上角：**保存为常用路线**。

| 场景 | 说明 |
|---|---|
| 手动输入路线后 | 想沉淀为常用路线 |
| 调整完行程段后 | 想保存为下次模板 |
| 配好常用资源后 | 想下次直接带出资源草稿和参考价 |

### 2. 保存弹窗字段

| 字段 | 默认 | 说明 |
|---|---|---|
| 路线名称 | 当前路线名称 | 可修改 |
| 默认天数 | 当前天数 | 自动带出 |
| 保存行程段 | 勾选 | 保存行程段名称、目的地、天数 |
| 保存资源配置 | 勾选 | 保存资源类型、供应商/承接方、资源名称 |
| 保存参考价格 | 勾选 | 保存金额作为参考价 |
| 保存客源信息 | 禁用 | 不保存 Partner、游客、人数 |
| 保存应收应付 | 禁用 | 不保存收付款节点 |
| 保存流水核销 | 禁用 | 不保存收付款记录 |

提示文案：

> 常用路线仅保存路线、行程段、资源配置和参考价格，不保存客源单、收付款节点和流水信息。
