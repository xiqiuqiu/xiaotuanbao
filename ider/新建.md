# 新建发团

> 领域术语见 `CONTEXT.md` 与 `docs/adr/0002-departure-domain-model.md`。  
> 交互参考：旅业通「新建团单」概念图（2026-07）；领域模型与 Tab 结构以小团宝 PRD 为准，**不**照搬 Day 级行程、独立游客名单 Tab、费用汇总 Tab。

## 一、入口与整体形态

**入口**：发团列表页主按钮 **新建发团**。

**形态**：宽 Drawer 或 Modal 内的 **两步向导**（非单页堆叠所有字段）。

| 步骤 | 标题 | 内容 |
|---|---|---|
| Step 1 | 选择路线 | 常用路线卡片 / 手动输入 |
| Step 2 | 填写发团信息 | 基础信息表单 + 已选路线摘要 |

顶部展示 **Steps 步骤条**（1 选择路线 → 2 填写信息）。底部：**上一步** / **下一步** 或 **创建发团**。

地接社建团心智为「先定线路、再定团期」；两步向导比单页 Drawer 更清晰，也避免未选路线就误保存。

---

## 二、Step 1：选择路线

### 1. Tab 切换

| Tab | 说明 |
|---|---|
| **常用路线** | 卡片网格 + 搜索（默认 Tab） |
| **手动输入** | 填路线名称与默认天数，不选模板；路线来源记 `manual`，**不** 弹复制确认窗 |

### 2. 常用路线卡片（网格）

搜索框置于 Tab 内容区顶部，支持按路线名称模糊搜索。

每张卡片展示：

| 字段 | 说明 |
|---|---|
| 路线名称 | 如「西安-青海湖-茶卡6日游」 |
| 默认天数 | 如「6 天」 |
| 使用次数 | 该模板被用于建团的累计次数（`usageCount`） |
| 最近使用 | 可选，第二版；第一版可仅展示使用次数 |

第一版 **不做** 路线类型标签（如「国内游」）；若需识别，用路线名称或备注区分。

卡片点击即选中；选中态高亮边框。支持 **单选**。

### 3. 底部固定条（Step 1）

选中常用路线后，Drawer 底部展示：

```text
已选：西安-青海湖-茶卡6日游（6 天）  [清除]     [下一步]
```

- **清除**：取消选中，禁用「下一步」
- **下一步**：先弹出 **使用该路线建团** 确认窗（见 §三），确认后进入 Step 2

**手动输入 Tab**：填完路线名称（必填）与默认天数（可选）后，底部 **[下一步]** 直接进入 Step 2，**跳过** 复制确认窗。

---

## 三、选择常用路线后的确认项

在 Step 1 点「下一步」后，弹出轻量 Modal：

**标题**：使用该路线建团

| 复制内容 | 默认值 | 控件 | 说明 |
|---|---|---|---|
| 复制行程段 | 勾选 | 可选 | 自动生成当前发团行程段 |
| 复制资源配置 | 勾选 | 可选 | 自动生成资源草稿（含拼出种类草稿） |
| 带出参考价格 | 勾选 | 可选 | 金额作为参考价格 |
| 复制客源 | 不勾选 | **禁用** + Tooltip | 「客源每次不同，不能从模板复制」 |
| 生成应收应付 | 不勾选 | **禁用** + Tooltip | 「收付款节点不能从模板复制」 |

主按钮：**使用该路线建团**（非「确定」）。取消则留在 Step 1。

复制完成后，常用路线与发团实例 **脱钩**——后续改模板不影响已建发团。建团成功时该模板 `usageCount + 1`。

## 四、Step 2：填写发团信息

### 1. 布局

- **左侧（主区）**：基础信息表单
- **右侧（摘要卡，只读）**：已选路线信息

摘要卡示例（选模板建团）：

```text
已选路线
西安-青海湖-茶卡6日游
默认 6 天｜将复制 2 段行程、5 项资源草稿
```

手动输入时摘要卡展示用户填写的路线名称与天数，复制行文案为「无模板复制项」。

### 2. 字段设计

| 模块 | 字段 | 必填 | 说明 |
|---|---|---|---|
| 建团方式 | 选择路线 | 是 | Step 1 已完成；此处只读展示或摘要卡呈现 |
| 建团方式 | 路线来源 | 系统记录 | 常用路线、手动输入、复制发团 |
| 基础信息 | 团名 | 是 | 默认按路线名称 + 出团日期生成，可修改 |
| 基础信息 | 团号 | 是 | 默认自动生成，可手动修改；旁侧 **重新生成** 按钮 |
| 基础信息 | 发团类型 | 是 | 独立团、拼团（展示标签，默认拼团） |
| 基础信息 | 出团日期 | 是 | 团开始日期 |
| 基础信息 | 结束日期 | 是 | 选择路线后可按默认天数自动计算 |
| 基础信息 | 团期天数 | 是 | 系统自动计算（结束 − 开始 + 1） |
| 基础信息 | 发团负责人 | 是 | 计调负责人，默认当前 User |
| 基础信息 | 备注 | 否 | 特殊说明 |

**团号重新生成**：点击刷新图标调用 API 生成新团号（org 内唯一），替换输入框内容。

**日期联动**：修改出团日期 → 若已从模板带出默认天数，自动重算结束日期与团名中的日期部分。

### 3. 底部操作

```text
[上一步]                              [创建发团]
```

创建成功：关闭向导 → 跳转发团详情页 `?tab=overview`（或客源 Tab，产品可再定）。

## 五、与概念图的刻意差异

| 概念图（旅业通） | 小团宝 | 原因 |
|---|---|---|
| 用语「团单」 | **发团** | 产品用语 |
| 详情 Tab「行程安排」D1–D6 | **执行安排** Tab（区内行程段导航 + 资源主表） | 规划单元为 Segment；段与资源同屏，非独立 Tab |
| 独立 Tab「游客名单」 | 名单在 **客源单抽屉** | 客人归属客源单 |
| Tab「费用汇总 / 账单明细」 | 头部 Read Model + 应收/应付/核销 | PRD Out of Scope |
| 建团时勾选「生成应收应付」 | 禁用；建团后 **显式触发** | ADR：保存源事实不生成节点 |

## 六、保存为常用路线

### 1. 入口

发团详情页右上角：**保存为常用路线**。

| 场景 | 说明 |
|---|---|
| 手动输入路线后 | 想沉淀为常用路线 |
| 调整完行程段后 | 想保存为下次模板 |
| 配好常用资源后 | 想下次直接带出资源草稿和参考价 |

### 2. 保存弹窗字段

| 字段 | 默认 | 说明 |
|---|---|---|
| 路线名称 | 当前路线名称 | 可修改 |
| 默认天数 | 当前天数 | 自动带出 |
| 保存行程段 | 勾选 | 保存行程段名称、目的地、天数 |
| 保存资源配置 | 勾选 | 保存资源类型、供应商/承接方、资源名称 |
| 保存参考价格 | 勾选 | 保存金额作为参考价 |
| 保存客源信息 | 禁用 + Tooltip | 不保存 Partner、游客、人数 |
| 保存应收应付 | 禁用 + Tooltip | 不保存收付款节点 |
| 保存流水核销 | 禁用 + Tooltip | 不保存收付款记录 |

提示文案：

> 常用路线仅保存路线、行程段、资源配置和参考价格，不保存客源单、收付款节点和流水信息。

### 3. 保存成功反馈

保存成功后：

1. **Toast**：「常用路线已保存，可在新建发团时选用」
2. Modal 关闭，留在当前详情页
3. 可选第二版：**「去新建发团试用」** 链至列表页并打开新建向导

## 七、复制已有发团（列表操作）

列表操作列 **复制** 与新建向导 **共用 Step 2 表单**，但 Step 1 跳过：

- 路线来源记 `copy`
- 复制段/资源/参考价（与模板规则相同）
- **不** 复制客源、收付款节点、流水
- 团名、团号、日期、负责人需重新填写或重新生成

可在 Step 2 摘要卡注明：「复制自发团 TDxxxx，不含客源与财务」。
