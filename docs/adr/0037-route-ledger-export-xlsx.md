# 线路视图筛选结果可导出为多 Sheet Excel（客源日报 + 资源安排）

计调在线路视图按线/按日扫读后，需要把当前筛选命中的各团日报带走，并在客源表后附上本团资源安排。决定提供 **服务端** `route-ledger.xlsx`（查询参数与线路视图读接口相同）：一个文件、每个发团一个 Sheet；Sheet 上半为与线路视图一致的客源列（含合计行），下半为资源安排事实区（种类、名称、供应商、约定金额、备注、所属行程段；含拼出与发团级资源），**不含**应付已付/未付进度。空壳发团仍出 Sheet。入口为筛选栏单一「导出 Excel」。不替代发团运营表（ADR-0018 / ADR-0033）；资源读模型可复用运营表快照中的安排事实，列裁剪为本导出口径。文件名 / Sheet 名见产品约定（路线或日期区间 + 导出日；`月日_团号`）。
