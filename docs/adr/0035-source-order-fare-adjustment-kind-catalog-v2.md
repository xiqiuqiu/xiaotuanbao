# Simplify Source Order fare-adjustment kind catalog

status: accepted

客源单 **团款调整种类** 收敛为六项（儿童门票补款 / 单房差补款 / 续住费用 / 门票优惠退差 / 住宿费用扣减 / 其他费用调整），取代 ADR-0031 后果中的细分清单与「自定义」逃生口。前五项固定方向、同单每种最多一行；「其他费用调整」方向自选、调整说明必填、可多行。字段「自定义名称」改为 **调整说明**（固定种类可选填）。结算公式、与整单优惠并存、finance-touched 锁定等 ADR-0031 其余决定不变。当前处于开发阶段，**不做**旧种类历史数据迁移。

## Considered Options

- 仅换抽屉 UI、保留 ADR-0031 种类表 — 否决；产品要一并调整业务分类，原型已体现新清单
- 去掉自定义但仍保留多项「门票已优惠过」细分固定种 — 否决；录入负担高于现场区分价值，合并为「门票优惠退差」
- 「其他费用调整」同单也最多一行 — 否决；需保留原自定义的多行逃生能力
- 一次性迁移并合并历史旧种类行 — 否决；开发阶段无保留旧枚举必要

## Consequences

- 取代 ADR-0031 Consequences 中的固定种类清单与「自定义」逃生口描述；ADR-0031 关于「调整与优惠并存、净额展示、金额锁定」的决定仍有效
- 枚举与校验随新目录替换；`CONTEXT.md` 中 Fare Adjustment Kind / Note 已同步
- 客源单抽屉 UI（加宽纵排、锚点 Tab、一行式录入、底部结算预览）在实现规格中落地，不改变收款拆分与生成应收口径
