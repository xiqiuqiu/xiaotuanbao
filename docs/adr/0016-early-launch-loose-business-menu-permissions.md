# 初期上线：计调与财务业务 Menu Permission 临时对齐

> **已被 ADR-0023 取代。** 该过渡态（财务=计调、开菜单即可写）已收回，权限提升到按钮级并落实计调/财务长期边界。以下为历史记录。

产品初期协作需要计调与财务都能查看并操作发团与财务相关业务，但第一版只有 Menu Permission、Preset Role 映射全局固定且不可按 Organization 配置。决定在过渡期内将计调与财务的业务菜单对齐为同一集合（发团、财务四菜单、合作伙伴、供应商；开菜单即可写），`/system/*` 仍仅企业管理员；不改 `CONTEXT.md` 中财务/计调的长期职责定义，收回边界以后再定。曾考虑租户级开关或操作级只读，但与 ADR-0001 及「第一版无读写拆分」冲突且成本过高；全局放开可接受，因近期 Organization 数量少。落地时 `PRESET_ROLE_MENU_KEYS` 与 seed 必须双向同步 RolePermission（多删少补），避免以后只改常量却收不回库内映射。
