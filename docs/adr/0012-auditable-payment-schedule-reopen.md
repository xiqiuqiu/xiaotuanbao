# 关闭的收付款节点可审计地重新打开

收付款节点关闭表示当下停止追收/追付，不是删除、作废或放弃未结清金额。当关闭依据后续被撤销核销等新事实改变时，财务人员可在原因必填且完整保留原关闭履历的前提下重新打开原节点。打开后按当前有效核销与到期日重新派生结清进度，恢复后续收付操作，但不新建节点、不清除财务履历。

## Considered Options

- **关闭绝对不可恢复**：拒绝。关闭后撤销核销可能使未结清金额增大；若不能打开原节点，又禁止重新生成，会形成无法继续收付的流程死路。
- **通过新建节点恢复追收/追付**：拒绝。会破坏财务生成一次性和原资源/客源单的履历连续性。

## Consequences

- 关闭后撤销核销不自动打开节点；财务人员根据商业事实决定是保持关闭还是明确重新打开。
- 关闭、关闭后撤销核销与重新打开均进入节点操作时间线。
- 重新打开恢复登记收付与匹配流水，但不恢复普通金额编辑；财务履历仍为真。
