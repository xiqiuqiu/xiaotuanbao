# 按日行程段骨架、发团级资源锚点、执行班组与团上收入

计调日常对照纸质「行程日报表」：多日线路按天配酒店/门票/拼出，全程用车/保险/导服挂整团，标题记司机导游车牌，另登记车销等团上收入。既有模型以跨日行程段为唯一成本锚点，且 CONTEXT 写明「第一版不做每日行程 / 班组仅备注 / Avoid 行程日报」，会挡住本迭代实现。决定在 **不引入独立「行程日报」实体或第二套工作台** 的前提下升级执行安排（权威输入：`docs/prd/departure-daily-execution-crew-ground-income.zh-CN.md`、Issue #199）。

## Decision

1. **按日行程段骨架**：可按发团出团日～回团日（`startDate`～`endDate`）一键生成 **一日一段** 的 Itinerary Segment；段名/目的地可后填。仍是行程段，不是 `DailyReport`。已有跨日段不强制拆日；一键生成按需使用。段内资源（含拼出）规则不变。每段可录票型人数（全/半/学/免）；与客源人数不一致时醒目提示，默认可保存。
2. **发团级资源锚点**：成本费用行除挂行程段外，可挂 **发团**（全程用车、保险、导游等）。Resource Kind、供应商类别校验、显式生成应付、finance-touched / 作废与重开等 **与段资源同一套**；计入成本合计与资源付款进度分母。
3. **执行班组（发团级）**：结构化字段——司机（供应商类别须含用车）、导游（须含导游）、车牌（自由文本）、联系电话（自由文本）。与成本资源完全分离：**选班组不生成应付**，不草稿化导游/用车应付。本迭代仅发团级一组，不做段级多班组轮换；不在供应商档案上维护车牌/驾驶员字段。
4. **团上收入台账**：（**已由 ADR-0036 取代**）原为发团下多行自由标题 + 金额、无品类枚举；概览「其他收入」= 台账合计；不经收付款节点。现由团内增收记录承接。

## Considered Options

- **新建独立「行程日报」实体 / 并行工作台**：拒绝。双轨维护与现有执行安排冲突；Avoid 仅针对此双轨，不禁止按日段能力。
- **全程费用仍强制塞进某一日段**：拒绝。与纸质「整团车费/保险/导服」习惯不符。
- **班组即导游/用车资源行（选人即成本）**：拒绝。负责人指派与应付义务生命周期不同；混用会导致误生成应付。
- **团上收入走其他应收或流水汇总**：拒绝。本迭代先闭环台账与概览展示；账款/资金层后置。

## Consequences

- CONTEXT：行程段允许一日一段执行骨架；运营表允许结构化班组；Avoid 禁止独立日报双轨，不禁止按日段；新增发团级资源、执行班组、团上收入、其他收入等规范名。
- ADR-0002 成本侧补充发团级资源锚点；应付仍显式触发。
- 实现主 seam：发团执行安排编排（含概览其他收入读取）；不新开平行日报引擎。
