# 复制发团只复用结构，不复制旧团业务事实

复制已有发团用于快速复用路线与执行结构，而不是克隆一次真实出团。决定复制基础信息、行程段与段资源结构，资源金额归零；不复制客源、游客、财务记录、发团级资源、执行班组、正式附件、团内增收或旧团实际供应关系。复制后按新团期校验并自动补齐未覆盖日期的一日一段骨架，所有结果随新发团脱钩管理。

## Considered Options

- **复制客源、财务或实际供应关系**：拒绝。这些是旧团已发生的业务事实，带入新团容易产生误收付、误联系或误执行。
- **复制资源金额**：拒绝。金额是旧团在当时人数、日期与商务条件下的结果，不是稳定模板值。
