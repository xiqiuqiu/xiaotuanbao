# 重新打开归档发团的账款前先解除发团归档

已关闭发团是对整个运营容器的归档只读决定，比发团已结清更强。归档期间仅可查看：财务不能直接撤销核销、作废或新增反向流水、调整金额或重新打开节点，也不能由这些操作自动解除整个发团归档。若需纠错或继续处理，必须先由 OP 或企业管理员在原因必填且保留原归档履历的前提下，将发团解除归档并回到待结算，之后再由财务执行具体动作。

## Considered Options

- **财务重新打开节点时自动解除发团归档**：拒绝。发团归档同时约束行程、客源与资源等运营信息，不能由单个财务节点操作隐式解除。
- **归档后永久不能再处理**：拒绝。后续可能发现录入、核销或商业事实错误，必须保留可审计的解除归档入口。

## Consequences

- 解除归档后发团回到待结算，但原收付款节点保持各自当前状态，不会全部自动打开。
- 归档期间只能查看；包括撤销核销与作废错误流水在内的财务纠错也须先解除归档。
- OP 或企业管理员负责解除发团归档；财务负责之后的具体节点处置。
- 发团解除归档和节点重新打开是两个独立、均可追溯的业务动作。
