# 重新打开节点时同步撤销发团已结清

发团处于已结清时不能同时存在开放的收付款节点。财务在已结清发团下明确重新打开节点时，必须先看到并确认联动影响；系统将节点恢复开放与发团回退待结算作为同一个不可分割的业务动作，两者分别留痕。该联动回退不需要 OP 预先审批，但必须对 OP 可见；节点之后再次全部结清或关闭时，发团不自动恢复已结清，仍由 OP 手动确认。

## Considered Options

- **节点重新打开但发团保持已结清**：拒绝。会同时存在「发团已结清」与「仍有开放追收/追付」两个互相矛盾的事实。
- **要求用户先在发团页回退状态，再回财务页打开节点**：拒绝。跨页两步会产生中间不一致状态，也把一个业务决定拆成两次操作。

## Consequences

- 重新打开已结清发团下的节点时，界面必须明确提示发团将回到待结算。
- 财务可直接确认该联动操作，无需 OP 预先审批；节点重新打开原因和发团结清撤销均可追溯且对 OP 可见。
- 子节点之后再次全部结束，只会让账款结束门槛恢复为真，不会自动改发团状态。
