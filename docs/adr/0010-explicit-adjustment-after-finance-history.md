# 有财务履历后的金额修正走明确调整

收付款节点曾发生核销后，即使最后一笔有效核销被撤销，也不回到「从未财务介入」并恢复普通金额编辑。为同时避免静默重写历史义务与永久锁死纠错，节点未关闭且有效核销为零时，允许通过原因必填的明确调整动作：资源应付同步修正原资源约定金额与原应付节点；客源应收按节点来源定位客户补款或游客代收路径，同步修正对应路径金额与原应收节点，且不得静默改动同一客源单的其他路径。调整保留前后金额、原因与操作人。

## Considered Options

- **撤销最后一笔核销后直接恢复普通编辑**：拒绝。会把「当前无有效核销」误当成「从未有财务履历」，允许无原因重写历史义务。
- **一旦发生财务履历就永久锁死金额**：拒绝。现实中仍需修正录入错误或处理重新议价，必须有可审计的纠错入口。

## Consequences

- 有效核销金额是可逆的当前结清事实；财务履历是不可逆的历史事实，两者必须分开派生。
- 调整不新建收付款节点，也不改变财务生成一次性规则。
- 仍有有效核销时须先撤销相关核销；节点已关闭时不可调整。
- 客源应收拆分收款下，各路径独立调整。在 ADR-0033 代收轧差模型下，**不要求**「客户补款路径 + 游客代收路径 = 结算金额」；游客代收合计 G 可大于 S，客户补款与返利由 `S`/`G` 轧差表达。调整单条路径时仍不得静默改动同单其它路径，并保留原因与前后金额审计。
