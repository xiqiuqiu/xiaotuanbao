# 应收到期日按出团月下月 10 日；应付本版不逾期

收付款节点两侧对「到期日 / 逾期」不对称：应收需要约定账期并驱动 `overdue`；应付本版不做账期催付。应收到期日在从客源单生成时默认按发团出团日所在月的下一自然月 10 日写入（快照，出团日变更不回写；未财务介入可手改）。应付仍可存到期日占位（生成时写结束日），但状态派生永不进入 `overdue`，产品 UI 不暴露应付到期日与「已逾期」筛选——拒绝用极大日期假装账期，以免污染数据并在日后真开应付账期时难洗。

## Considered Options

- 应付写入 `9999-12-31` 哨兵日期以「防逾期」——否决：假日期，筛选/排序无意义，日后难迁移
- 应付 `dueDate` 改可空——否决：本版不值得动 schema
- 存量应收到期日批量回写——否退：账期是已沟通事实，未介入可手改即可
