# 发团摘要分开账款核销进度与资金进出

发团财务摘要不再用一组「已收/未收、已付/未付」同时承担账款结清与资金发生两种语义。账款层明确展示已核销与未结清应收/应付；资金层另行提示归属该发团的未核销收入/支出。这使「已实际支出 4000，但对该应付的有效核销为 0」可被如实表达，无需创造「已放弃金额」。

## Considered Options

- **继续用「已付/未付」表示有效核销**：拒绝。撤销核销后会显示已付为零，误导用户认为没有发生资金支出。
- **按发团下全部流水表示「已付」**：拒绝。未核销流水尚未证明结清了哪笔义务，不能减少应付节点的未结清。

## Consequences

- 撤销 4000 元核销后，若原应付为 10000 元，发团可同时展示「已核销应付 0 / 未结清应付 10000」与「未核销支出 4000」。
- 应收侧对称展示已核销应收、未结清应收与未核销收入。
- 发团账款结束门槛仍只由收付款节点是否已结清或已关闭决定；未核销资金是待处理财务事项，不自动改写节点状态。
