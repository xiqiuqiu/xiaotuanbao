# 发团概览 B 款：三层结构与当前毛利含增收

Grilling 确认的发团概览 B 款（原型 `overviewVariant=B`）将主视图收敛为 **待办提醒 → 经营概况横条 → 收付款进度** 三层纵向结构，并调整当前毛利与收付进度口径。本 ADR **部分 supersede ADR-0020** 的概览展示层与主收付进度定义；**ADR-0004**（Finance Facade、原子财务快照、守恒异常、经营事实与财务事实分层）与 **ADR-0011**（账款核销进度与资金进出分离）继续有效，不在此重复。

## Decision

### 1. 概览主视图三层结构

1. **待办提醒**（最上）：并行拉取客源单、行程段、账款等待办项；点击跳转对应 Tab。
2. **经营概况横条**：一行展示收入构成（原始团款、调整净额、优惠、结算应收、增收净收益、收入合计）、成本构成（资源成本、拼出成本、成本合计）、当前毛利与毛利率；**不展示总人数**。
3. **收付款进度**（最下）：收款进度与付款进度各一卡；**不再**在主视图独立展示团款收款进度、游客代收进度、返利、资金情况四层中的后三项。

团款收款进度、游客代收、返利、资金情况等口径仍可在明细入口、其他 Tab 或运营表中查阅；概览主层不再强制展示。财务对照与异常仍按指标就近展开，不新增独立财务对照大区块。

### 2. 当前毛利含增收

- **结算应收**（= 客源团款合计 `netReceivableCents`）不变：原始团款 + 调整净额 − 优惠合计。
- **增收净收益**（= 本团增收记录公司增收合计）仍不并入结算应收或收款进度分母。
- **收入合计** = 结算应收 + 增收净收益。
- **当前毛利** = 收入合计 − 成本合计。
- **毛利率** = 当前毛利 ÷ 收入合计 × 100%；收入合计为零时显示「暂无数据」。

此决策 **部分 supersede ADR-0036** 第 2 条「第一期不并入当前毛利主指标」中关于概览当前毛利的表述；增收记录仍不生成收付款节点、不计入资源成本或应付合计。

### 3. 收付进度口径（概览主层）

| 指标 | 分子 | 分母 |
|------|------|------|
| **收款进度** | 已提交应收的已核销合计 | 已提交应收合计（= 已核销 + 开放未结清 + 已关闭未收） |
| **付款进度** | 资源应付有效核销合计 | 成本合计 |

收款进度表达「已提交应收账款的收回进度」，**不再**使用 ADR-0020 的团款收款进度（结算应收为分母、`min(Guest已收,S)+补款已收` 分子）。付款进度与 ADR-0020 主层付款进度一致：资源应付已核销 ÷ 成本合计；手工应付、其他应付、返利应付及资源账款差异不混入分子，全部应付已付 ÷ 确认应付留在明细。

### 4. 展示规则（自 ADR-0020 继承）

- 毛利率、收款进度、付款进度四舍五入固定显示 1 位小数（如 `80.0%`）；分母为零显示「暂无数据」。
- 主层指标金额为零时显示 `¥0.00`；明细入口内提示项金额为零时省略该行。
- 比例文字保留负数或超过 100% 的真实值；进度条仅在视觉上限制为 0–100%。
- 资源账款差异不为零时付款进度可合法超过 100%；存在尚未生成应付时进度系统性偏低——由明细入口解释，不做截断或修正。

## Considered Options

- **保留 ADR-0020 四层结构与团款收款进度**：拒绝。B 款 grilling 确认主视图只需待办、经营横条与收付两层经营信息；团款/代收/返利/资金独立层信息密度过高且与日常扫读目标不符。
- **当前毛利仍只用结算应收**：拒绝。增收净收益是真实经营收入，排除后低估毛利；纳入收入合计后毛利率与横条构成自洽。
- **收款进度仍用结算应收为分母**：拒绝。概览收付层对齐「已提交账款」进度，与待办「待提交应收」及财务工作流一致；团款口径保留在明细与运营表。

## Consequences

- **Supersede ADR-0020**：概览四层信息结构、主层展示总人数、主层团款收款进度/游客代收/返利/资金情况独立卡、以及收款进度口径；付款进度分子分母含义与 ADR-0020 主层一致，继续有效。
- **ADR-0004 / ADR-0011 仍有效**：Finance Facade 原子快照、守恒异常、账款与资金分层、确认应付构成等不因概览简化而合并口径。
- **实现分票**：UI/API 对齐见父 Spec #274 子票；`packages/shared` 中 `additionalIncomeNetCents` 等字段注释仍写「不并入当前毛利」的清理留给 **#276**，本 ADR 为权威域口径。
- 原型 `apps/web/src/features/departure/prototype/departure-overview/` 中 B 款为结构参考；落生产后移除 throwaway host。
