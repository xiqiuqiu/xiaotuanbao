# AI 候选证据核验同一事实，不要求字面子串

ADR-0046 要求候选能追溯到本批 User 消息、当前业务事实或固定档案解析版本，禁止用滚动摘要当写入证据。#321 把「可追溯」落成摘录必须是原文逐字子串、系统推导只认快照已有字段；一句话口述团期（中文日期、天数、人数）会被整包拒绝，并被记成 Agent 不可用。

决定：**可追溯 = 系统能核验候选值与来源为同一事实**，不要求摘录与规范字段值字面相同。同一审核包内已通过核验的候选可参与确定性推导；「N 天 / N 日游」按含首尾计，结束日 = 开始日加 (N−1) 个自然日。未确认候选仍不是业务快照。证据指向本批原文内容，不指向内部消息编号。原文不能确定完整日历日（含年）时，不得用今天或空草稿补年。核验失败则整包不落库、草稿不变，对 User 说明无法追溯到来源，不与模型超时或权限失败混用。
