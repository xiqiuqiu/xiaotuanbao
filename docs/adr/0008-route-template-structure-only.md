# 常用路线只固化执行安排结构，不存资源金额

常用路线（Route Template）的价值是把 Organization 内相对固定的线路切段与段内资源草稿（种类、对手方、名称等）沉淀为目录，供建团时少录一遍执行安排。段内资源金额是本团总价，通常随人数等变化，存进模板会伪装成可复用的「参考价」，因此模板不持久化有业务意义的金额（`amountCents` 列保留但写入与存量迁移后恒为 0）。服务端固定复制执行安排结构且金额为 0，并删除对外 `copySegments` / `copyResources` / `copyReferencePrices` 标志。复制进发团后即本团事实，与模板脱钩。产品侧后续去掉分层 copy 确认窗、保存弹窗仅保留名称与默认天数、删除 `fromTemplate` 角标与字段、以及建团卡片删除模板等（分 issue 落地）。模板维护第一版仅支持删除（建团选路线卡片 + 确认），更新靠另存新名；组织内同名禁止。

建团采用常用路线时，模板行程总天数必须与 User 所选团期一致。不一致时拒绝创建并要求调整模板或团期；系统不自动改结束日，也不截断、压缩或保留团期外行程段。

## Considered Options

- **保留「参考价格」可选勾选**：拒绝。资源金额是总价而非单价，与人头强相关，默认勾选会误导沿用。
- **行程段 / 资源配置分项勾选**：拒绝。详情已合并为「执行安排」一体工作区；后端资源挂在段下，分项勾选易产生无效组合。
- **建团 / 复制仍弹 copy 确认窗**：拒绝。与「固化后就是为了下次直接带出结构」的场景冲突；空手建团走手动输入即可。
- **保留行程段「模板」角标与 `fromTemplate`**：拒绝。脱钩后继续展示来源无操作价值，徒增噪音。

## Consequences

- 领域用语见 `CONTEXT.md` Route Template；产品文案与 `ider/新建.md` 等需去掉参考价与分层 copy 表述。
- API 契约（#78）：创建发团 / 复制发团 / 从发团保存常用路线不再接受分层 copy 标志；结构恒复制、资源金额恒 0；存量模板资源金额迁移清零。
- UI / schema 收尾（#79–#82）：删除确认窗与分层勾选、简化保存弹窗、去掉 `fromTemplate`、建团卡片删除模板等另开 issue，不阻塞 #78。
- 无行程段不可保存为常用路线；有段无资源可保存。删除模板不影响已建发团（`sourceTemplateId` 仅追溯、非外键）。
- 行程段日期仍须落在当前发团出团日～结束日内；模板不存绝对日历，建团按新出团日与段 `dayCount` 分配日期。
