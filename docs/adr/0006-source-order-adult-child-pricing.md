# Source Order adult/child pricing

客源单团款从「总人数 × 单一单价」改为按成人/儿童分别录入人数与单价；原始应收（Gross Receivable）派生为成人人数 × 成人团款单价 + 儿童人数 × 儿童团款单价。总人数仍持久化为派生字段供列表与汇总；单一 `unitPriceCents` 在迁移回填后删除，API 不再接受旧单价/总人数入参。客人名单是计调备忘，不回写客源单人数，并移除「同步人数」。

## Considered Options

- 保留单一单价、仅备注区分成人儿童 — 无法按类计价，否决
- 长期保留 `unitPriceCents` 作成人单价兼容 — 双源真相，否决
- 名单变更自动同步人数 — 名单无计价分类且非事实来源，否决

## Consequences

- 历史客源单迁移为「全员成人、儿童为 0」，编辑时金额不变
- 财务已介入时成人/儿童人数与单价与优惠、收款拆分一并锁定
- 列表去掉「原始团款单价」列，「客人人数」改称「总人数」
