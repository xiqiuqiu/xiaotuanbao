# 团内增收记录取代团上收入台账

计调除团款外还需登记购物店返利、车销、自费返利等附加收入及导游提成；既有 **团上收入台账**（自由标题 + 金额、无类型、无提成/结算标记，概览「其他收入」= 合计）不足以支撑。产品决议：**用团内增收记录整表替换团上收入**，不并存两套录入。权威输入：`ider/团内增收记录功能_PRD.md`；UI 原型选定方案 A（统计 + 表格 + 抽屉）。部分取代 **ADR-0034** 第 4 条。

## Decision

1. **替换而非并存**：发团详情「增收记录」页签为唯一录入面；移除概览内团上收入台账 CRUD；旧 `ground_incomes` 一次性迁为类型「其他增收」（项目名称=原标题，提成 0，收入未收、提成未付），随后下线旧模型与文案。
2. **台账边界不变**：收入状态（未收/已收）与提成状态（未付/已付）仅为跟进标记；**不**生成应收/应付、**不**要求流水；不计入资源成本或应付合计；第一期不并入当前毛利主指标。
3. **概览与命名**：经营补充独立卡为 **增收净收益**（= 各条 **公司增收** 合计；公司增收 = 增收金额 − 导游提成）。行内/表单用「公司增收」，汇总卡与运营表合计用「增收净收益」——同一公式。
4. **协作字段**：合作方复用 Supplier，四种类型均可空（购物店/自费弱提示）；导游默认执行班组导游，可改选导游类供应商，可空。权限第一期沿用发团可编辑。
5. **运营表**：有数据时分区「增收记录」，列含类型、项目、合作方、增收金额、导游提成、公司增收、综合状态；合计为增收净收益。

## Considered Options

- **与团上收入并存**：拒绝。双口径与双入口会混淆计调，迁移与概览指标也无法单一解释。
- **标记已收即生成其他应收 / 提成已付即生成应付**：拒绝。第一期先闭环登记与跟进；账款层后置（与 ADR-0034「不经收付款节点」一致）。
- **概览三卡（增收/提成/净收益）**：拒绝。经营补充区以一张净收益主卡扫一眼即可；明细进页签。
- **第一期拆计调/财务按钮级权限**：拒绝。状态不进账款时细拆收益有限；沿用发团编辑权限。

## Consequences

- CONTEXT：退役「团上收入台账 / 其他收入（概览卡）」规范名；新增团内增收记录、公司增收、增收净收益。
- ADR-0034 决策第 4 条由本 ADR 取代；按日段 / 发团级资源 / 执行班组条款不变。
- 实现需迁移脚本、页签与概览/运营表口径同步；原型代码不进生产路径。
