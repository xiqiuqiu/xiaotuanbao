# 节点关闭记录处置类型与具体说明

存在未结清时关闭收付款节点，记录的不是「放弃了多少金额」，而是为何停止当前节点追收/追付。关闭必须选择「转外部或专项处理」「商务争议停止跟进」或「其他」处置类型，并填写具体说明；系统同时保留关闭当时的约定、已核销、未结清快照与操作信息。

## Considered Options

- **只要求一段自由文本原因**：拒绝。会让金额变更、核销错配与错误流水都被便捷地塞进关闭，无法稳定区分处置路径或汇总原因。
- **将未结清标为已放弃金额**：拒绝。关闭只停止当前追收/追付，不自动消灭商业义务或改写约定金额。

## Consequences

- 暂时未收/未付的节点应保持开放；关闭是明确停止当前流程的处置。
- 商业金额重新议定走约定金额调整；错误核销走撤销核销；错误流水走作废或反向资金记录。
- 「其他」仍必须填写可审计的具体说明。
