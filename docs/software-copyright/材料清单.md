# 软著提交材料清单（小团宝）

提交前逐项勾选。鉴别材料文件见 `output/`。

## 本仓库已准备（鉴别材料）

- [ ] `output/小团宝旅行社运营管理系统V1.0-源代码.docx`（单面打印，核对页眉/页码/最后一页为程序结束）
- [ ] `output/小团宝旅行社运营管理系统V1.0-使用说明书.docx`（单面打印，核对页眉与申请表名称版本一致）
- [ ] 申请表字段草稿已按 [申请表填写稿.md](./申请表填写稿.md) 誊到版权中心在线系统

## 企业单独申请（常见）

- [ ] 申请表（单面打印；第三页盖企业公章）
- [ ] 源码文档（单面打印）
- [ ] 使用说明书（单面打印）
- [ ] 企业营业执照复印件（盖公章）
- [ ] 经办人/代理人身份证复印件（正反面）

## 个人单独申请

- [ ] 申请表（单面打印，签名）
- [ ] 源码文档（单面打印）
- [ ] 使用说明书（单面打印）
- [ ] 申请人身份证复印件（正反面）
- [ ] 若代理申请：代理人身份证复印件 + 委托说明（委托人签字）

## 多人 / 多企业 / 合作或委托

在对应清单基础上额外准备：

- [ ] 合作开发协议或委托开发协议（各方签字或盖章）
- [ ] 申请表「开发方式」选合作开发或委托开发（勿误选独立开发）
- [ ] 全部著作权人身份证明

## 打印与装订自检

- [ ] 全部材料单面打印（双面易被退回补正）
- [ ] 源码、说明书页眉软件全称与版本号与申请表一致
- [ ] 右上角有页码
- [ ] 源码每页约 ≥50 行；说明书每页约 ≥30 行（有图除外）
- [ ] 源码最后一页为完整结束（常见以 `}` 结尾）
- [ ] 申请表「源程序量」带「行」字单位
- [ ] 说明书/截图无真实客户、政府、银行等具名敏感数据
- [ ] 申请表各页流水号打印完整

## 补正常见项（提前规避）

| 问题 | 处理 |
| ---- | ---- |
| 邮箱收不到补正通知 | 尽量留常见个人邮箱；可联系版权中心补正组重发 |
| 只改正一页申请表 | 建议整份申请表重打并重新签章 |
| 行数与文档页数明显矛盾 | 重新生成 60 页源码文档，并同步改申请表行数 |
