# 小团宝 · 软件著作权材料准备

本目录依据 [China-software-copyright](https://github.com/AlexanderZhou01/China-software-copyright) 的材料规范，为当前仓库「小团宝」准备软著登记所需鉴别材料与填写底稿。

**正式提交仍须在中国版权保护中心（或当地代办窗口）在线填表、打印盖章；本仓库只准备可打印的鉴别材料与字段草稿。**

## 建议登记名称

| 字段 | 建议值 | 说明 |
| ---- | ------ | ---- |
| 软件全称 | 小团宝旅行社运营管理系统 | 与页眉、说明书标题保持一致 |
| 软件简称 | 小团宝 | 可填；也可留空 |
| 版本号 | V1.0 | 全文统一，勿写 `v1.0` / `1.0.0` 混用 |
| 软件作品说明 | 原创 | 非修改件 |
| 开发方式 | 独立开发 / 合作开发 / 委托开发 | 按实际权利归属选择；合作/委托须附协议 |
| 权利取得方式 | 原始取得 | 自行开发通常选此项 |
| 权利范围 | 全部 | 常见选法 |
| 鉴别材料 | 一般交存 | 源程序前+后各 30 页；文档前+后各 30 页（不足则全部） |

## 本目录产出

| 文件 | 用途 |
| ---- | ---- |
| [材料清单.md](./材料清单.md) | 按申请主体类型核对提交物 |
| [申请表填写稿.md](./申请表填写稿.md) | 在线申请表字段草稿（含功能与技术特点） |
| [使用说明书.md](./使用说明书.md) | 用户使用说明书源稿（有界面，选使用说明而非设计说明） |
| `output/小团宝旅行社运营管理系统V1.0-使用说明书.docx` | 可打印说明书（含页眉页码） |
| `output/小团宝旅行社运营管理系统V1.0-源代码.docx` | 可打印源程序（前 30 + 后 30 页） |

| `scripts/generate_source_doc.py` | 从仓库源码生成源代码 docx，并统计行数 |

## 格式硬性要求（审核高频）

### 使用说明书

- 页眉：软件全称 + 版本号（与申请表完全一致）；右上角页码。
- 每页不少于约 30 行（有图除外）；一般不足 60 页则全部提交。
- **单面打印**；勿出现真实客户名、具体商户/政府单位名称等敏感样例数据。

### 源代码文档

- 前连续 30 页 + 后连续 30 页（共 60 页）；不足 60 页则全部提交。
- 每页不少于约 50 行；**去掉空行**；最后一页应为程序结束（常见以 `}` 结尾）。
- 建议文档开头放启动入口代码（本项目为 `apps/api/src/main.ts`）。
- 页眉：软件全称 + 版本号；右上角页码；**单面打印**。
- 申请表「源程序量」须写单位，例如 `104767行`，不要只写数字。

### 申请表

- 企业申请：第三页申请人签章处盖公章。
- 合作开发勿选「独立开发」；须附合作/委托协议。
- 打印后核对流水号是否完整显示。

## 生成 / 刷新材料

在仓库根目录执行：

```bash
# 依赖：python3 + python-docx
pip install python-docx

# 生成使用说明书 docx
python3 docs/software-copyright/scripts/generate_manual_doc.py

# 生成源代码 docx（并打印建议填入申请表的源程序量）
python3 docs/software-copyright/scripts/generate_source_doc.py
```

源码有较大变更后，请重新跑一遍上述脚本，再核对申请表行数。

## 你方还需人工准备的材料

脚本无法代替的部分（见材料清单）：

1. 著作权人身份证明（个人身份证双面复印件，或企业营业执照复印件并盖章）。
2. 在线填表后打印的《计算机软件著作权登记申请表》并签字/盖章。
3. 若合作开发 / 委托开发 / 代理申请：对应协议与代理人身份证明。
4. **开发完成日期、首次发表日期、著作权人法定名称与证件号**等法定信息。
