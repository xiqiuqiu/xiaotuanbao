# 当前设计对齐与回归

2026-09-07。依据 [PRD #483](../../../prd/2026-09-07-business-object-agent-collaboration.md)、客源 v0.3 与资源 v0.13。本记录替代旧 QA 对最新原型的结论；旧截图保留为历史证据。

## 本轮调整

- 设计模型、改造指引、ADR-0055、原型 README 和覆盖表统一到当前设计。移除早期全局入口、默认全表编辑和建团前置的现行描述。
- 客源名单只展示/编辑姓名、电话、性别、备注；不再强制核实年龄和电话类型。支持候选增删与本次录入选择，缺姓名可明确排除，计费人数不受影响。
- 调整使用六类和固定方向，其他说明必填；金额须为合法人民币精度。业务备注与结算说明分开，客户结算不显示代收轧差。
- 模式切换不套用金额，同次编辑可恢复各模式草稿；正代收允许超过结算额。分拆初始应收为尾款代收和适用客户补款，全部代收区分定金/尾款，零节点不生成，返利不自动支付。
- 资源编辑不含容量/数量/单价字段；八类、静态供应商匹配、名称、正总价和备注。容量信息作为材料对照，只提醒，不阻断合法费用。
- 资源成功后先选择本次成功且未提交的资源子集，再独立准备应付审核；不默认全选。
