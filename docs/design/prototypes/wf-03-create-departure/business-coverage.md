# 当前原型覆盖与生产设计边界

2026-09-07。依据 [#483 PRD](../../../prd/2026-09-07-business-object-agent-collaboration.md)；不得将原型限制当作需求。

| 范围 | 当前可演示 | 生产接入尚需实现 |
|---|---|---|
| 对象协作 | 已有发团入口、侧栏展开、四分类、相关会话、稳定三栏 | 服务端对象关联、本人历史查询与恢复 |
| 材料 | 可见完整示例、联合客源与资源提案、文本文件读取 | OCR、任意内容识别、真实证据定位 |
| 客源 | 报价、六类调整、优惠、三种收款模式、分离备注、名单四字段与选择 | 真实客户目录、缺失集中澄清、同类多事项、完整冲突与版本策略 |
| 客源计算 | 精确到分、代收>0、超额代收可用、模式草稿隔离 | API字段映射、事务和精度/换算确认流程 |
| 段资源 | 三条材料示例、八类选择、静态供应商匹配、正总价、备注、容量提醒不阻断 | 真实供应商状态及类别、目标段验证、独立确认服务端事务 |
| 发团级资源 | 普通业务页人工新增及归属示意 | 部分跨日整体报价的 Agent 提取和审核 |
| 初始应收 | 创建后继续、正金额路径、同客源整体确认 | F1原子事务、F2历史异常、F3按操作权限 |
| 初始应付 | 创建后选择成功资源子集、独立审核 | 持久接收、多项执行、部分失败与共同前置中止 |
| 结果 | 内存结果、同会话回看、正式页面示意 | 刷新/跨设备恢复、历史版本和提交结果未知回查 |
| 业务环境 | 目录、建团、增收、流水、核销的已有演示入口 | 不属于本期新增 Agent 能力的承诺 |

每模板单份候选、固定一团和财务提案覆盖限制仅用于演示；生产必须支持同类多事项和持久历史。刷新原型会重置，不可据此设计生产清空会话或数据。

历史 QA 与 WF-01/02 线框仅代表记录时刻。最新人工回归见 [current-design-qa.md](current-design-qa.md)。
