## 0. 领域术语对齐（grill-with-docs）

本轮已将产品中心核心语言写入 glossary，并记录两条难逆决策。实现与 `/to-spec` 须使用下表规范名，勿把常用路线或发团叫作「产品」。

| 规范名 | 中文 | 要点 |
|--------|------|------|
| **Product** | 散拼产品 | 营销与报价资料聚合根；第一期类型仅散拼 |
| **Product Type** | 产品类型 | 第一期固定散拼，无多类型切换 |
| **Product Schedule** | 班期 | 日期规则 + 报价口径；≠ 发团；≠ 收付款节点 |
| **Product Spec** | 价格规格 | 默认销售价档；≠ 客源团款单价 |
| **Product Schedule Price Snapshot** | 班期价格快照 | 创建时从规格复制；改默认价不回写班期（ADR-0025） |
| **Product Itinerary** | 产品行程 | 营销文案整体；≠ 行程段 / 执行安排 |
| **Short / Detailed Itinerary** | 简版 / 详细行程 | 总表快发 vs 正式文档 |
| **Product Day** | 产品日行程 | D1/D2 营销条目；可先不拆日 |
| **Product Feature** | 产品特色 | 营销卖点；可空 |
| **Booking Notice** | 报名须知 | 年龄/拼住/退改等；可与特色分模块 |
| **Product Status** | 产品状态 | 草稿 / 销售中 / 已下架 |
| **Product Schedule Status** | 班期状态 | 销售中 / 已截止 / 已取消 |
| **Product Departure Source** | 产品发团来源 | 发团上追溯指针；copy-on-create 脱钩（ADR-0026） |

**相关 ADR：**

- [ADR-0025](../../adr/0025-product-schedule-price-snapshot.md) — 班期报价为创建时快照，不活引用规格默认价  
- [ADR-0026](../../adr/0026-product-schedule-generates-departure-by-copy.md) — 由班期生成发团为复制脱钩，价不进财务  
- [ADR-0027](../../adr/0027-s3-compatible-object-storage.md) — 附件 S3 兼容对象存储 + StoredObject；开发期 Garage  
- [ADR-0008](../../adr/0008-route-template-structure-only.md) — 常用路线只固化执行结构（与 Product 正交）

**明确分界：**

- Product ≠ Route Template（常用路线）≠ Departure（发团）  
- Product Itinerary / Product Day ≠ Itinerary Segment（行程段）  
- Product Schedule ≠ Payment Schedule（收付款节点）  
- 班期销售价不写入客源单价、不触发生成应收

## 1. 背景与目标

地接社（试点：西部中旅）当前用 Excel 汇总散拼产品，表内嵌或关联 Word 详细行程，再通过微信把资料发给同行。痛点是资料分散、班期与价格重复维护、内容难复用、版本难检索。

**试点目标：**

- 把「疆游记大巴总表」迁入小团宝并结构化，降低改价与发版成本。
- **不强迫大幅改变工作习惯**：对外仍以 Word/PDF（及过渡期总表 Excel）经微信发送。
- 班期确认后可生成现有**发团**，进入客源/执行/财务闭环。

**成功标准（试点）：** 计调对本季产品主要在系统内改价与改简版行程，用导出文件发给同行；需要出团时从班期生成发团，而不再以手工 Excel 为主维护面。

## 2. 非目标（试点期不做）

- 同行在线商城、公开产品页、在线报名/支付/余位库存
- 渠道专属价、佣金、分销关系
- 任意第三方 Excel 版式自适应（只吃透西部中旅这一本模板）
- 产品成本与毛利测算、AI 自动报价
- 自由拖拽式 Word 模板设计器
- 用产品中心取代或合并「常用路线」
- P0/P1 阶段的「生成团单」、跨产品班期总视图、完整 PRD 七页签一次性交付

## 3. 领域边界

| 概念 | 职责 | 与本试点关系 |
|------|------|----------------|
| **Product（散拼产品）** | Product Itinerary、Product Spec、Product Schedule、对外文档 | 本设计主对象 |
| **Departure（发团）** | 一次具体出团的运营容器（客源、资源、财务） | P2 由 Product Schedule 生成；Product Departure Source 追溯后脱钩 |
| **Route Template（常用路线）** | 仅固化行程段/资源结构（ADR-0008） | 不自动写入；发团后可按现能力另存 |

```text
客户 Excel 总表 + Word
        │
        ▼
   Product（产品行程 / 规格 / 班期 / 导出）
        │                    │
        │ 导出 Word/PDF/Excel │ P2 选 Product Schedule + 具体出团日
        ▼                    ▼
   微信发给同行              Departure（copy 脱钩 + Product Departure Source）
                              │
                              └── 可选：保存为 Route Template（仅结构）
```

**不变量（与 ADR-0025 / 0026 一致）：**

- 产品改价/改 Product Itinerary **不回写**已生成发团。
- 发团变更**不回写**产品。
- 班期销售价**不**写入客源单价、**不**触发生成应收。
- 改 Product Spec 默认价**不回写**既有班期快照。

UI：菜单「产品中心」；对象称「产品」「班期」。发团主名称仍为「发团」；操作文案可用「生成团单」但语义生成 Departure（以 `CONTEXT.md` 为准）。

**策略代号 D：** 渐进交付；试点客户只适配西部中旅《疆游记》大巴总表。

|------|----------|----------|----------|

## 5. 西部中旅模板映射

样本工作簿含 5 个 Sheet，例如：北疆大巴纯玩线路、南北疆大巴连线（单卧）、北疆+喀什连线（单卧）、喀什起止大巴/7 座拼车、伊宁起止大巴/7 座拼车。表头含全局「注意事项及说明」；数据区典型列为：

| Excel | 系统对象 | P0 要求 |
|-------|----------|---------|
| Sheet 名 | 产品分组或标签 / 导入批次维度 | 写入可筛选来源 |
| A 列线路名与标签词（如「经典热卖款」「A线：…」） | 产品名称；营销标签尽量拆出 | 名称必填 |
| B 列简版 D1…Dn | 简版行程（可先整段文本） | 必填 |
| C 列产品特色 /「真心」 | 产品特色（整段或拆条） | **可空** |
| D–G 班期多行（说明、成人、儿童、单房差） | 多条班期 + 价格快照 | ≥1 条候选项，或明确「无报价行」 |
| 表头注意事项 | 组织级报名须知模板候选 | P0 可整段保留，P1 挂接 |
| 内嵌 OLE Word | 详细行程 | **P0 不解析、不强挂**；P1 可后补 |

班期原文常不规整（「天天发团」「每周一、五接站」「7月2380」等）：**始终保留原文**；能解析则填区间与金额；不能解析则班期仍建、日期待确认，**不得**自动当作可销售班期参与上架统计。

## 6. P0：迁入

### 6.1 流程

1. 上传该 xlsx（试点可限定组织或识别为「疆游记总表」模板）。
2. 按 5 个 Sheet 扫描线路块（合并单元格 + A/B/C/D 区块）。
3. 确认页：原表摘要对照 + 结构化候选项；价格与班期日期**一律人工确认**。
4. 批量生成**草稿**产品（不上架）；原文件归档可回看。
5. 列表可按「导入批次」筛选。

详细 Word / OLE：确认页可提示「检测到 N 个内嵌文件，P1 再关联」，**缺失不阻断迁入**。

### 6.2 每条产品必落 / 可空

**必落（接受时）：** 产品名称、简版行程文本、状态=`草稿`、Sheet 来源；班期侧至少一条带成人价的候选项，或明确标记无报价。

**可空：** 产品特色、详细行程、封面、费用含/不含结构化、报名须知拆条、多规格、出发/结束城市、天数（空则编辑页标「待完善」）。

P0 默认一个规格占位（如「标准」），班期价挂在该规格上。

### 6.3 验收

- 5 个 Sheet 均出现在导入结果中（空 Sheet 可报「无线路」）。
- 被接受的线路具备名称、简版、班期规则如上。
- 确认前不上架、不生成发团。
- 原 xlsx 可下载；OLE 缺失不失败。

## 7. P1：最小编辑与导出

### 7.1 信息架构（收窄）

一级菜单：**产品中心**。

- 产品列表（默认）：导入批次、状态、Sheet 标签筛选
- 产品编辑：**单页分块**（不做完整七 Tab）
- 导出：列表或编辑页触发

跨产品班期视图、批量调价 → P1.5 / P2 之后。

### 7.2 编辑分块

| 区块 | 能力 |
|------|------|
| 基础信息 | 名称、标签、起止城市、天数、状态；Sheet 来源只读 |
| 简版行程 | 整段编辑；可选「按 D1/D2 拆日」（可撤销）；失败则保持整段 |
| 产品特色 | 可空；整段或拆条 |
| 报价 | 单规格 + 班期列表（原文说明、日期区间可空、成人/儿童/单房差、备注） |
| 报名须知 | 可挂组织模板或整段粘贴 |
| 详细行程 | 可空；粘贴/上传 Word 后补 |

**班期价格快照：** 创建班期时复制规格当前价；改规格默认价**不回写**既有班期；班期价可独立改。

### 7.3 导出

1. **单产品同行资料**：PDF 优先，Word 次之。含标题/标签、简版、特色（有则出）、班期表、须知（有则出）。选项：有价 / 无价。
2. **总表 Excel（过渡）**：列近似旧表，按 Sheet 标签分 sheet 或分区，降低戒断感。

导出前校验：有名称、有简版；勾选有价则至少一条有效成人价。特色/详细/须知缺失只警告不拦截。

### 7.4 上架

**销售中**建议满足：名称 + 简版 + ≥1 条可展示班期（有成人价或明确「询价」标记）。特色、详细 Word、结构化须知**不是**上架门槛。草稿可导出（可选文件名/水印标「草稿」）。

### 7.5 验收

- P0 草稿可改价、改简版；快照不被默认价误覆盖。
- 单产品 PDF（有价/无价）可读性接近旧同行资料习惯。
- 可导出覆盖本批次五 Sheet 产品的近似总表 Excel。
- 全程可不填特色、可不挂详细 Word。

## 8. P2：班期 → 生成发团

### 8.1 入口

- 产品编辑页班期行：「生成团单」（生成发团）
- 产品列表「更多」：先选班期再生成

### 8.2 前置

| 条件 | 行为 |
|------|------|
| 产品非已下架 | 草稿生成须二次确认 |
| 班期非已取消 | 已取消禁止；已截止二次确认 |
| 出团日可确定 | 区间班期须再选**具体出发日**；点状班期直接用该日 |
| 结束日 | 有则用；无则 `出团日 + 天数 - 1`；天数也无则手工补 |

### 8.3 字段映射

| 来源 | 发团 | 规则 |
|------|------|------|
| 产品名称（±班期名） | 线路名称 | 可改 |
| 选定出团日 | 出发日期 | 可改 |
| 推算/原结束日 | 结束日期 | 可改 |
| 天数 | 与现发团一致 | — |
| 简版（整段或已拆每日） | 行程文本草稿 | 复制；能拆则按日，否则整段备注/说明 |
| 产品 ID + 班期 ID | 来源引用 | 只读追溯，非活引用 |
| 内部备注 | 发团备注候选 | 可空 |

**不带入：** 销售价→应收/客源单价；特色/须知默认不进发团（可选进内部备注，默认关）；详细 Word 可不拷；供应商/资源/成本不从产品生成。

### 8.4 与常用路线

生成发团**不**自动写常用路线。若仅有营销文本而无行程段结构，发团行程区可为文本备注 + 空壳段，由计调再补或套用常用路线——第一版可接受，避免把营销行程硬塞成资源结构。

### 8.5 其他规则

- 同一班期允许多个发团；生成时提示已有 N 个并发链接。
- 权限与现发团可写角色对齐（计调/企业管理员可生成；财务不可）。
- 发团编号走现有组织业务前缀，不用产品编号冒充发团号。

### 8.6 验收

- 销售中产品某班期可选出团日并生成发团，详情可见来源。
- 生成当时不出现由产品价产生的应收；客源团款仍手录。
- 改产品报价后，旧发团内容不变。
- 同一班期可第二次生成并发出提示。

## 12. AI 与后续迭代

**不阻塞 P0–P2 主路径。** 主路径跑通后，按既有 AI 一期设想增强：旧 Word/PDF 导入确认、行程润色与简版生成、多形态文案、导出前内容检查。关键字段（价格、日期、年龄、退改等）必须人工确认；AI 不直接改关键业务数据。

后续产品化方向（非本试点范围）：多租户模板适配、同行分享链、余位、渠道价、成本毛利、详细 Word 与 OLE 自动对齐等。
