# 小团宝 Agent 交互改造实施指引

当前设计 · 2026-09-07。本文取代早期 Draft 的入口、页面组织与执行范围描述。唯一交互需求依据为 [PRD #483](../prd/2026-09-07-business-object-agent-collaboration.md)，不建立第二份竞争 PRD。

## 本期范围

已有发团内的客源单新增与选定名单、段资源及发团级资源新增和待审修订、创建后初始应收/应付、结果回看与恢复。建团、行程新增、全局财务代理、历史账款修复不作为本期前置或隐含扩展。用户继续可用普通业务表单。

## 实施约束与对应文档

| 主题 | 当前约定 | 细节依据 |
|---|---|---|
| 入口 | 业务侧栏与同一会话的对象工作区，无独立全局聊天 | [交互模型](agent-interaction-model.zh-CN.md) |
| 左栏 | 对象摘要、四分类、相关协作记录；全过程结构稳定 | PRD 的会话与布局约定 |
| 中栏 | 唯一聊天壳，材料、澄清、来源与反馈 | PRD 的材料与会话约定 |
| 右栏 | 多事项列表、审核、组内修订、结果；确认按钮吸底 | PRD 的审核行为 |
| 客源 | 报价、固定调整、优惠、三种收款方式、分离备注及选定名单；未知不归零 | [客源 v0.3](../specs/2026-09-07-agent-source-order.md) |
| 执行资源 | 八类、有效供应商、名称、正总价、备注与归属；容量只提醒 | [资源 v0.13](../specs/2026-09-07-agent-execution-resources.md) |
| 初始账款 | 创建成功后另行选择、审核；客源节点整体、资源逐项；历史异常不自动修复 | 两份业务规格 F1–F3 |
| 权限 | 对应普通业务操作的实时权限；会话本人和组织隔离 | 技术方案第4、9节 |
| 版本与恢复 | 稳定事项身份、预期版本、持久确认、业务写入与回执同事务；未知先查 | [技术方案 v0.10](../specs/2026-09-07-agent-collaboration-technical-plan.md)第9节 |
| 验收 | 材料→审核→修订→确认→正式记录；部分失败、并发、刷新与权限 | 技术方案第10节和各任务票 |

字段枚举、计算公式及校验不以原型实现作为定义。禁止继承年龄/电话类型必填、代收不得超结算、容量不足禁止录费、创建前选择应收、一个阶段一个待审包等旧约束。

## 开发任务

无需新建 PRD 或重复拆票。#447 先完成底座，#446/#449/#450 接入客源及资源，#451/#452 接入初始账款，#454 完成结果回看，#455 做集成异常验收，#456 可提前准备材料。实际开工按 GitHub 原生依赖。

`ready-for-agent` 表示规格已明确，不代表实现通过验收。开发不得通过修改 PRD 迎合旧代码限制，也不得把真实数据库验证尚未完成再次变成产品待决。
