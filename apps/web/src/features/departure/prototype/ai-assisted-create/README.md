# AI 辅助新建发团 · 双模式 UI 原型

> **问题**：在现有 `/departure/new` 页面中，表单录入与 AI 助理怎样随时切换、共享同一份草稿，并把候选审核与阶段进度表达清楚？

## 启动

```bash
pnpm prototype:ai-assisted-create
```

浏览器（需已登录）：

http://localhost:5173/departure/new?prototype=ai-assisted-create&variant=A

## 方案

| 键 | 结构 | 主要判断点 |
|---|---|---|
| **A** | 现有表单主场 + 右侧 AI 侧栏 | 熟练用户是否最容易理解与切换 |
| **B** | 左侧 AI 主场 + 右侧实时草稿 | 对话引导与结构化反馈是否最自然 |
| **C** | 阶段任务台 + 独立审核门 | 跨客源、行程、资源的长流程是否更稳 |
| **D** | 定稿合成：A 主场 + C 审核 | 熟悉表单、阶段治理与确认写入能否同时成立 |

切换：`?variant=A|B|C|D`，或底部浮动条 / ← →。

## 人工选择

2026-08-12：选择 **A 为主、融入 C**。方案 D 是该选择的合成验收稿。

## 丢弃

原型只使用 Mock 数据。定稿后按选中结构重写正式实现，勿直接 import 本目录。
