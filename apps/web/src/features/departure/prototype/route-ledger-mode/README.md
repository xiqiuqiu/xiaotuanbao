# 线路视图 · 收入/成本模式 UI 定稿

> **定稿**：一团日报用 **Radio 实心按钮组** 切换「客源收入 / 执行成本 / 拼出往来」，配合右上财务汇总条与分面表格。

## 启动

```bash
pnpm prototype:route-ledger-mode
```

浏览器打开（需已登录）：

http://localhost:5173/prototype/route-ledger-mode

## 交互摘要

| 区域 | 行为 |
|---|---|
| **视图切换** | 线型 Tab：发团视图 / 线路视图（与线上一致） |
| **日报分面** | Radio 按钮组：客源收入 / 执行成本 / 拼出往来 |
| **财务汇总** | 头部右侧常驻：结算｜成本｜拼出｜毛利 |
| **收入表** | 序号～备注全列 + 合计行（单数、人数、各金额列） |
| **成本表** | 序号、归属日程、资源类型、项目、供应商、金额、备注 + 合计 |
| **拼出表** | 序号、拼出方、说明、金额、备注 + 合计 |

原型页「导出 Excel」位于**筛选栏右侧**（与正式线路视图一致），导出 **当前筛选结果**：

- 选了路线 → 单路线导出（文件名含路线名）
- 仅选日期 → 该区间内所有 Mock 发团
- 无匹配发团时按钮禁用

实现：`prototype-export.ts`（浏览器 Mock，不影响线上 API）。

## 数据说明

Mock 数据在 `shared.ts`，**只读**，不接 API。
